# 用語集

| 用語 | 意味 |
|---|---|
| **章(chapter / entry)** | `content/foundations/*.md` の 1 件。解説・手順・クイズを持つ |
| **frontmatter** | Markdown の先頭の `---` で囲んだ構造化データ |
| **`operationSteps`** | 章の手順の一覧(`label`・`menuPath`・`note`)。図になる |
| **`quiz`** | 章末クイズ。`answer` は選択肢の番号(0 始まり) |
| **`guide`** | 「この章の見方」(見るポイント・注意・誤解)。書いた項目だけ出す |
| **`claim`** | 章の主張を 1 文で。「ひとことで」として出る |
| **masteryBadge** | 習得の印(習得済み・復習すべき・今後学ぶ・応用・発展) |
| **分類表(taxonomy)** | カテゴリ・サブカテゴリの表。章の分類は、これと一致させる |
| **規則表** | 正規表現と結果の対応表。**最初に当たった規則を採る**(`step-scene.ts`) |
| **`OVERRIDES`** | 規則で外れる章だけを、id で直接上書きする表 |
| **グリフ** | 手順に当てる線画のアイコン(約 45 種) |
| **`pipeline` / `cycle`** | 平面の図の型。蛇行する流れ / 輪 |
| **`stack` / `helix` / `ring` / `tree` / `color` / `mesh`** | 立体の図の型。層・らせん・輪・木・RGB 立方体・分割 |
| **`solidFirst`** | その章で、立体を既定にするか |
| **登録表(レジストリ)** | `id in 表` で、対応の有無を調べる表(`hasAnimation`) |
| **決定論的** | 同じ入力から、いつも同じ出力。乱数・時刻を使わない |
| **ハイドレーション** | サーバーで作った HTML に、ブラウザで操作の機能をつなぐこと |
| **先に予想(Guess first)** | 次の手順を先に選ばせる任意の機能。採点も記録もしない |
| **出どころの札(ProvenanceTag)** | 測定 / 読み取り / 模擬 / 推測 の 4 つで、情報の出どころを示す |
| **つながりの地図** | 本文のリンクから集めた「参照している章 / 参照されている章」。前提とは断定しない |
| **スクロールスパイ** | スクロール位置に合わせて、目次の現在位置を強調する仕組み |
| **間隔反復** | 忘れる頃に再出題する学習法。ここでは固定の 1・3・7 日 |
| **localStorage** | ブラウザの、端末ごとの保存領域 |
| **three.js** | ブラウザで 3D を描くライブラリ。立体を選んだときに読み込む |
| **WebGL** | ブラウザの 3D 描画の仕組み。使えない環境では平面に戻る |
