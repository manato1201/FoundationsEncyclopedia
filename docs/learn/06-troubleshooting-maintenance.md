# 6. トラブルと保守

## 症状から探す

| 症状 | 原因の候補 | 確かめ方・直し方 |
|---|---|---|
| 章が一覧に出ない | ファイルが `.md` でない・frontmatter の分類が表と不一致・`name` などの欠落 | 講義 第 1 回の検査 |
| 章ページが 404 | ファイル名(id)と URL が違う | ファイル名 = id |
| 図が出ない | `operationSteps` が無い(アニメーションの登録も無い) | frontmatter・`has-animation.ts` |
| 手順のアイコンが「step」ばかり | 規則に当たる語が、ラベルに無い | `GLYPH_RULES`・ラベルの語 |
| 立体が出ない・平面に戻る | WebGL が使えない環境 | 仕様(平面に戻る) |
| ループの章が、立体で「木」になる | 規則表の不具合(下の既知の問題 1) | `OVERRIDES` で個別に直すか、規則を直す |
| 復習の記録が消えた | 端末・ブラウザを変えた・データを消した | JSON の書き出しから復元 |
| 復習の問題が、別の問題になった | **章の中でクイズの順序を変えた**(記録のキーは `章の id#番号`) | 下の既知の問題 3 |
| 更新履歴に出ない | `updates.ts` に足していない | 先頭に足す |
| 文書の検査が落ちる | ソースが変わって、引用・実行例の出力が古い | `python tools/check_docs.py --update` のあと、**差分を読む** |

## 既知の問題・注意(読んで見つけたもの。コードは変えていない)

1. **ループの章の立体が、輪(`ring`)でなく木(`tree`)になる**。`tree` の規則の `oop`(オブジェクト指向を狙った語)が、**`loop` に部分一致**し、`tree` が `ring` より先に評価される。`game-loop-basics`・`for-loop-flow`・`javascript-event-loop-basics`・各言語の `…-loops-basics` など、**id に `loop` を含む 13 章**が該当する(平面は正しく `cycle`)。このうち Blender のループカット・Maya のエッジループは、本来は形(`mesh`)が主題かもしれず、**どの型が正しいかは章ごとに決める**必要がある。
2. **半数以上の章(252/495)は、どの規則にも当たらず、既定(`helix`・平面が既定)になる**。規則表は、主題が立体向きの 207 章を拾うが、残りは「らせん」の立体を(切り替えれば)見ることになる。意図した割り当てかは、未確認。
3. **復習の記録のキーが `章の id#問題の番号`**。章の中でクイズの**順序を変える・途中に足す**と、記録が別の問題に当たる(古い記録がずれる)。章の id を変えると、記録は切れる。
4. **復習の計算が、`localStorage` と一体**で、自動テストが無い(講義 第 5 回)。
5. **コンテンツの自動検査が無い**。分類の不一致・クイズの答えの範囲外などは、ビルドしても気づけない(いまのデータは、全件問題なし)。
6. **`chapter-links` は、起動のたびに全章の本文を読む**(結果はプロセス内にキャッシュ)。章が増えると、ビルドが遅くなる。リンクの形(`/foundations/<小文字・数字・ハイフン>`)から外れたものは、拾わない。
7. **更新履歴は手書き**。足し忘れると、画面に出ない。
8. **本文の HTML は、サニタイズせずに埋め込む**前提(リポジトリの中の信頼できる Markdown だけ)。外部の入力を足すなら、サニタイズが要る。
9. **立体は概念図**。実際の寸法・数値は表さない。実行環境の分離などの比較表は、公式ドキュメントでの確認が必要。

```javascript
// 実行できる
(async () => {
  const s = await import("./src/lib/step-scene.ts");
  // 既知の問題 1: loop の章の立体が、tree になる(意図は ring)
  const ids = ["game-loop-basics", "for-loop-flow", "python-loops-basics"];
  console.log(ids.map((id) => `${id}=${s.resolveScene(id).solid}`).join(" / "));
  console.log("/oop/ が loop に当たる:", /oop/.test("loop"));
})();
```

```text
# 出力
game-loop-basics=tree / for-loop-flow=tree / python-loops-basics=tree
/oop/ が loop に当たる: true
```

## 定期の保守

| いつ | 何を |
|---|---|
| 月に 1 回 | `npm audit`・依存の更新(**Next.js は脆弱性が出やすい**)。更新後に `build` |
| Next.js・React を上げたとき | `npm run build` と、カタログ・章ページ(平面・立体)を目で確認 |
| three.js を上げたとき | 立体 6 種を、それぞれ目で確認 |
| 章を足したとき | その章を開いて、図・アイコン・クイズ・目次を確認。`updates.ts` に足す |
| 規則表を変えたとき | **全章の結果を前後で比べる**(学習資料 4 のレシピ C) |
| 文書を触ったとき | `python tools/check_docs.py` |

## 直す前の確認

1. 規則表の変更は、**全章**に影響する(部分一致の事故に注意)。
2. 章の id・クイズの順序を変えると、**復習の記録が切れる・ずれる**。
3. **乱数・時刻を、描画に使っていないか**(サーバー描画との食い違い)。
