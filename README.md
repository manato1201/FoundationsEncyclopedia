# FoundationsEncyclopedia

基礎的な内容をまとめたリポジトリです。プログラミング言語・IT知識・DCC・ツール・フレームワークの基礎を、CSSのステップアニメーションで順番に見られる図鑑です。

- 本番: https://foundations-encyclopedia.vercel.app
- 技術: Next.js 16 / React 19(静的生成)
- コンテンツ: `content/foundations/*.md`(frontmatterの `operationSteps` でステップ表示、`quiz` で章末クイズ)

## 開発

```bash
npm install
npm run dev
```

## 画面デザインの決めごと表

迷いやすい点は、ここで先に決めておく(`IMPROVEMENT_DESIGN_2026-10.md` 参照)。

| 項目 | 決めごと |
| --- | --- |
| 光(glow) | 「いま見ているステップ」の要素だけ。静的な装飾には付けない。ライトテーマでは光の代わりに小さな影 |
| 色の役割 | 青 = 現在地・操作 / 緑 = 完了・正解 / アンバー = 注意・補足 |
| 数字 | 等幅数字(`data-tabular`)。進捗は `3 / 9` の形式 |
| アイコン | `src/components/icons/Icon.tsx` の線画セットだけを使う(文字の矢印は使わない) |
| 見出し | 見出し + 灰色の副題の2段 |
| テーマ | 同じトークン名でダーク/ライトを切替(`data-theme`)。初期値はOS設定 |
| 動き | `prefers-reduced-motion` と、ヘッダーの「動きを減らす」スイッチ(`data-motion="reduce"`)で止める。1画面で使う動きは2種類まで。通常画面は静かに保つ |
| タブ | 現在のタブは青の下線。章は「解説 / 例 / クイズ」(`ChapterContent`) |
| 視覚表現 | カタログの動きは2種類まで: ヒーローの順次点灯トラック(`HeroTrack`)と、カードの段階プレビュー(`StepPreview`、既定はホバー時のみ。「プレビューを動かす」で常時再生)。章ページはステップ一覧の完了チェックと現在ステップの入場アニメ |
| 目次 | 左の目次の現在の章の下に、ページ内の見出し(スクロールスパイ)を出す |

## 章ページの構成

左 = 同じ分類の目次 / 中央 = 見出し・ステップアニメ・解説 / アニメ枠の下 = ステップ操作(再生・戻る・進む・速度)。章末にクイズがある章では、間違えた問題を 1・3・7 日後にトップの「復習」へ出す(ブラウザのlocalStorage、固定間隔。将来FSRS等へ置き換え可)。

## ステップ操作

再生 / 前後 / リセット / 速度(0.5x・1x・2x)/ インジケーター(青 = 現在地、緑 = 通過済み)/ 「n / total」。枠にフォーカスがあるときは `,` で前、`.` で次へコマ送りできる。ステップ形式(`operationSteps`)の章では、直前のステップを薄く残す「直前を残す」と、スクロール量で進める「スクロールで進める」も使える(どちらも選んだときだけ有効)。

## 章の定型項目(`guide`)

frontmatter に `guide` を書くと、章の末尾に「この章の見方」を出す。書いた項目だけ表示する。

```yaml
guide:
  watch: 見るポイント
  caution: 使うときの注意
  misconception: よくある誤解
```

## 章の見せ方(anatomyの原則)

1. **次の1つだけ有効なステップボタン**: `CssStepAnimation` に `stepLabels` を渡すと、「次へ: ○○」の主ボタンが出る(`operationSteps` の章には自動で付く)。
2. **内部を見せる窓**: 装置の中身を、いまのステップに合わせて概念図で見せる(CPU・GPU・NPUの章から)。
3. **1文の主張**: frontmatter の `claim` に「GPUは同じ計算を一斉に行う」の形で書くと、見出しの下に「ひとことで」として出る。1文で言えない章は、2つに分ける。

分解ビュー(Exploded view)は、実行環境の分離の章で使っている(`IsolationLayersAnimation`)。層の数・順序は概念図で、実際の構成とは限らない。

画面右端の縦のレール(`ChapterRail`)は、章全体のうちの位置を示す。目盛りは見出しの位置で、クリック・ドラッグ・矢印キーで移動できる。左の目次(スクロールスパイ)は「どの見出しか」、レールは「全体のどこか」と役割を分けて併用する。幅1200px未満では出さない。

## 入口の段分け

カタログの入口は「まずはここから(`STARTER_IDS` の順)/ 用途から(`PURPOSE_GROUPS`)/ すべて」。どちらも `src/lib/catalog-entry-points.ts` に定義している。
