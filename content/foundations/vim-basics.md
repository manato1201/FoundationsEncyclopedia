## 概要

Vim(ヴィム)は、サーバーに接続したときなど、ターミナルだけの環境でよく使われるテキストエディタ。多くのLinuxに入っている`vi`と互換性があり、SSH([SSHの基礎](/foundations/ssh-basics))で入ったサーバーで、設定ファイルを直すのに役立つ。特徴は**モード**があること。キーの意味が、いまのモードで変わる。

## 基礎文法

| モード | 入り方 | できること |
| --- | --- | --- |
| ノーマル | 起動時、または Esc | 移動・削除・コピー・コマンド |
| 挿入 | i(カーソル前)・a(後)・o(下に新しい行) | 文字の入力 |
| ビジュアル | v | 範囲を選ぶ |
| コマンドライン | `:` | 保存・終了・検索置換 |

- 移動(ノーマル): `h`(左)`j`(下)`k`(上)`l`(右)。矢印キーも使える
- 編集(ノーマル): `dd`(1行削除)・`yy`(1行コピー)・`p`(貼り付け)・`u`(元に戻す)
- 検索: `/語` で検索、`n` で次の候補

## つまずきやすい点

- 「終了できない」が最初の壁。`Esc`を押してノーマルモードに戻り、`:q!`(破棄して終了)か`:wq`(保存して終了)を入力する
- 変更があると、`:q`は断られる。保存するか、`:q!`で破棄するかを選ぶ
- 日本語の入力方式(IME)がオンのままだと、ノーマルモードのキーが効かない。Escで戻ったときは、IMEをオフにする
- 読み取り専用のファイルや、権限のないファイルは、保存できない。`sudo`を付けて開き直す必要があることがある([ファイルパーミッション](/foundations/linux-file-permissions))

## 実装例(コード)

```bash
vim memo.txt
# i を押す → 「hello」と入力 → Esc → :wq と入力して Enter
cat memo.txt        # hello

vim +10 memo.txt    # 10 行目にカーソルを置いて開く
vimtutor            # 付属の練習用チュートリアル(入っていれば)
```
