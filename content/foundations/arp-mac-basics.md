## 概要

機器のネットワークカードには、固有の**MACアドレス**がある。同じネットワークの中では、通信の宛先はMACアドレスで決まる。そこで、IPアドレスからMACアドレスを調べる仕組みが**ARP**(Address Resolution Protocol)。

## 基礎文法

| 用語 | 意味 |
| --- | --- |
| MACアドレス | ネットワーク機器ごとの識別番号(同じネットワークの中で使う) |
| IPアドレス | ネットワークをまたいで使う住所 |
| ARPテーブル | IPとMACの対応を保存した一時的な表 |

## つまずきやすい点

- ARPが使われるのは、同じネットワークの中だけ。ほかのネットワークへ送るときは、ルーター(ゲートウェイ)のMACアドレスを調べる
- ARPの返事には認証がないため、偽の返事で通信を乗っ取る攻撃(ARPスプーフィング)がある
- ARPテーブルは、一定時間で消える。機器を入れ替えたあと、しばらく通信が不安定になる場合がある

## 実装例(コード)

```bash
arp -a   # 保存されているIPとMACの対応を表示する
```
