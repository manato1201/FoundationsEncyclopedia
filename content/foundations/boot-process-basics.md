## 概要

電源を入れてからOSが使えるようになるまでには、複数の段階がある。最初に動く小さなプログラムが、次に動くプログラムを読み込んで引き継ぐ。ファームウェア → ブートローダー → カーネル → サービスの順に進む。

## 基礎文法

| 段階 | 役割 |
| --- | --- |
| ファームウェア(BIOS/UEFI) | ハードウェアの初期化、ブートローダーの探索 |
| ブートローダー | カーネルをメモリに読み込む |
| カーネル | OSの核。デバイスやメモリの管理を始める |
| init / systemd | 各種サービスを起動する |

## つまずきやすい点

- 起動順序の設定(ブートの優先順位)を間違えると、意図しないディスクから起動する
- 複数のOSを入れる(デュアルブート)ときは、ブートローダーの設定が重要になる
- ブートローダーやカーネルが壊れると、OSが起動しない。修復用のメディアを用意しておく
