## 概要

ポリゴンモデリングの基本は、**面を押し出して形を作る**こと。さらに、**ベベル**で角を面取りすると、光が当たったときに、角が自然に光る。実物の角は、完全には鋭くないため、少しのベベルが、リアルさを増す。

## 基礎文法

| 操作 | 役割 |
| --- | --- |
| Extrude | 選んだ面や辺から、新しい面を押し出す |
| Bevel | 角を面取りして、細い面を作る |
| 分割数 | ベベルの丸みの滑らかさ |

## つまずきやすい点

- 押し出しを重ねたあと、重なった面や、見えない面が残る場合がある。形を確認して、不要な面を削除する
- ベベルの幅が大きすぎると、ほかの辺と重なって、形が崩れる
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import maya.cmds as cmds

cmds.polyExtrudeFacet("pCube1.f[0]", localTranslateZ=0.5)   # 面を押し出す
cmds.polyBevel3("pCube1.e[*]", fraction=0.3, segments=2)     # 辺をベベルする(フラグは版で異なる場合がある)
```
