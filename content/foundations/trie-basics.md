## 概要

**トライ木**(Trie)は、文字列の集合を、**先頭から1文字ずつ**枝分かれする木で表すデータ構造。「app」「apple」「apply」のように先頭が共通する単語は、共通の枝を共有する。接頭辞で始まる単語を探すのが速い。

## 基礎文法

| 操作 | 計算量 |
| --- | --- |
| 挿入・検索 | O(L)(Lは文字列の長さ) |
| 接頭辞で探す | O(L) + 結果の数 |

## つまずきやすい点

- 単語の数ではなく、文字列の長さに比例して時間がかかる。単語が増えても、検索の速さが変わりにくい
- ノードごとに子の入れ物を持つので、メモリを多く使う。文字の種類が多いと、さらに大きくなる
- 完全一致だけが目的なら、ハッシュテーブルのほうが簡単で速い。接頭辞検索が必要なときに、トライ木の利点が出る

## 実装例(コード)

```python
class Trie:
    def __init__(self):
        self.children = {}
        self.is_word = False

    def insert(self, word):
        node = self
        for ch in word:
            node = node.children.setdefault(ch, Trie())
        node.is_word = True
```
