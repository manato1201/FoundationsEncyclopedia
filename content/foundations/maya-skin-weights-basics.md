## 概要

スキンウェイトは、メッシュの各頂点が、どのジョイントにどの程度追従するかを表す数値。関節の周りで滑らかに変形させるには、頂点ごとに複数のジョイントの影響を混ぜて調整する。

## 基礎文法

| 用語           | 意味                                       |
| -------------- | ------------------------------------------ |
| スキンバインド | メッシュとジョイントを結びつける操作       |
| ウェイト       | 頂点がジョイントから受ける影響の強さ(0〜1) |
| 正規化         | 1つの頂点の影響の合計を1にそろえる         |

## つまずきやすい点

- 関節の周りは、2つのジョイントの影響を滑らかに混ぜる。境目が急だと、折れ曲がったように見える
- ウェイトは頂点ごとに値が決まるので、ポリゴン数が少ないと、細かな調整がしにくい
- ペイントで1つのジョイントを増やすと、ほかのジョイントの値が減る(正規化されているとき)。意図しない場所へ影響が移っていないかを確認する
- バインドをやり直すと、調整したウェイトが失われる場合がある。やり直す前に、ウェイトを書き出して保存しておく

## 実装例(コード)

```python
import maya.cmds as cmds

# ジョイントとメッシュをバインドする(名前は例)
cmds.skinCluster("joint1", "joint2", "pCylinder1", toSelectedBones=True)
```
