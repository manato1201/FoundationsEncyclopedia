## 概要

**ニューラルネットワーク**は、脳の神経細胞のしくみに着想を得た計算モデル。ひとつの**ニューロン**は、入力に重みを掛けて足し、活性化関数を通して出力する、単純な計算でしかない。これを多数、層状に並べると、画像の分類や文章の生成など、複雑な対応を学習できる。大きな言語モデルも、この仕組みを大規模にしたもの([トークンとコンテキストウィンドウ](/foundations/tokens-context-window))。計算に使われるハードウェアは[CPU・GPU・NPUの違い](/foundations/cpu-gpu-npu)を参照。

## 基礎文法

| 用語 | 意味 |
| --- | --- |
| 重み(w) | 入力の影響の強さ。学習で調整される |
| バイアス(b) | 出力の底上げ・下げ。学習で調整される |
| 活性化関数 | 非線形な変換(ReLU・シグモイドなど) |
| 層 | ニューロンの集まり。入力層・隠れ層・出力層 |
| 損失 | 予測と正解のずれを表す数値 |
| パラメーター | 重みとバイアスの総称。数が、モデルの大きさの目安 |

- 1つのニューロン: `出力 = 活性化(w1·x1 + w2·x2 + … + b)`
- 重みの調整は、損失を小さくする方向を計算して(勾配)、少しずつ動かす。細かな仕組みは、別の章の範囲

## つまずきやすい点

- 「脳と同じ」ではない。着想は神経細胞だが、実際の仕組みはまったく別物
- 活性化関数がないと、層を何枚重ねても、全体は1つの線形な関数と同じで、複雑な関係を表せない
- 学習に使ったデータに合いすぎて、新しいデータでは外れることがある(過学習)。学習に使わないデータで、確かめる
- 出力が確率のように見えても、正しさを保証するものではない([ハルシネーションと確認の方法](/foundations/hallucination-basics))

## 実装例(コード)

```python
# 2入力・隠れ層2ニューロン・1出力の、順伝播(重みは手で決めた例)
def relu(x):
    return max(0.0, x)

def neuron(inputs, weights, bias):
    return relu(sum(w * x for w, x in zip(weights, inputs)) + bias)

x = [1.0, 2.0]
h1 = neuron(x, [0.5, -0.2], 0.1)    # 0.5 - 0.4 + 0.1 = 0.2
h2 = neuron(x, [-1.0, 0.3], 0.0)    # -1.0 + 0.6 = -0.4 → ReLU で 0.0
y = neuron([h1, h2], [1.0, 2.0], 0.5)  # 0.2 + 0.0 + 0.5 = 0.7
print(h1, h2, y)
```
