## 概要

Unreal Engineでは、モデル・テクスチャ・マテリアル・Blueprint・レベルなど、ゲームに使うものを**アセット**と呼び、プロジェクトの`Content`フォルダの下に、専用形式(`.uasset`)のファイルとして保存する。それを一覧し、整理し、作成する窓が**コンテンツブラウザ**で、日常の作業の入口になる。

## 基礎文法

| 操作 | やり方 |
| --- | --- |
| 取り込み | ドラッグ&ドロップ、または Import(FBX・画像・音声など) |
| 新規作成 | 右クリック > 作成するアセットの種類を選ぶ |
| 移動・名前変更 | ブラウザ上でドラッグ / F2 |
| 参照の確認 | アセットを右クリック > Reference Viewer(何から使われているかを見る) |
| 検索 | 検索欄に名前、フィルターで種類を絞る |

- 取り込んだ元ファイル(FBXなど)は、ゲーム内ではアセットに変換されたものが使われる
- 別のプロジェクトへ持ち出すときは、アセットを右クリックして Migrate を使うと、依存するアセットもまとめて渡せる

## つまずきやすい点

- OSのエクスプローラーでアセットのファイルを動かしたり名前を変えたりすると、参照が壊れる。必ずコンテンツブラウザで操作する
- 移動のあとに、古い場所へ「リダイレクター」が残ることがある。Content Browser でフォルダを右クリックし、Fix Up Redirectors を実行して整理する
- 削除しようとしたとき、ほかから使われているアセットは、警告が出る。何から使われているかを確かめてから、判断する
- 名前の付け方(例: `SM_`で始まるスタティックメッシュなど)にチームの規則を決めておくと、検索しやすい。公式が決めた規則ではなく、慣習

## 実装例(コード)

```python
import unreal

# Python(エディタースクリプト)でアセットの一覧を調べる
paths = unreal.EditorAssetLibrary.list_assets("/Game", recursive=True, include_folder=False)
for path in paths[:10]:
    print(path)
```
