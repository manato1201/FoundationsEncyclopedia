## 概要

オブジェクトの回転や拡大は、**ピボット**を中心に行われる。ドアの蝶番の位置にピボットを置くと、正しく開く。**スナップ**は、グリッドや頂点、カーブなどへ、ぴったり吸着させる機能で、正確な配置に使う。

## 基礎文法

| 機能 | 役割 |
| --- | --- |
| ピボット | 回転・拡大の中心 |
| グリッドスナップ | 格子に合わせる |
| 頂点スナップ | 頂点に合わせる |

## つまずきやすい点

- ピボットを動かしたまま、ほかの作業に戻ると、思わぬ動きになる。編集の状態を終了する
- スナップをオンにしたまま作業すると、動きが引っかかって見える。必要なときだけ有効にする
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import maya.cmds as cmds

cmds.xform("door", pivots=(0, 0, 0), worldSpace=True)  # ピボットを原点に置く
```
