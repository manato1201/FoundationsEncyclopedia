## 概要

**トポロジー**は、メッシュの辺と面の**つながり方**。特に、形を一周する辺の輪(**エッジループ**)が、体の動きに沿って流れていると、変形がきれいになる。アニメーションするキャラクターで重要になる。

## 基礎文法

| 用語 | 意味 |
| --- | --- |
| エッジループ | 形を一周する辺の連なり |
| ポール | 辺が3本または5本以上集まる頂点 |
| クアッド | 4つの辺でできた四角形の面 |

## つまずきやすい点

- 三角形や5角形以上の面が多いと、変形やスムースで、ゆがみが出やすい
- ポールは、動きの大きな場所に置くと、変形が乱れやすい。目立たない場所に置く
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import maya.cmds as cmds

cmds.polySelect("pCube1", edgeLoop=0)  # 指定した辺を通るエッジループを選ぶ
```
