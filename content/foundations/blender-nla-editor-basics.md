## 概要

**NLA**(非線形アニメーション)エディターは、アニメーションの**まとまり(アクション)**を、**ストリップ**として並べたり、重ねたりして編集する画面。同じ動きを繰り返す、動きをつなぐ、といった作業を、キーを直接触らずに行える。

## 基礎文法

| 要素 | 役割 |
| --- | --- |
| アクション | キーフレームのまとまり |
| ストリップ | 並べたアクション |
| トラック | ストリップを並べる段 |

## つまずきやすい点

- アクションに名前を付けて、保存しておく。保存されていないと、使われないアクションは消える場合がある
- ストリップの重なりで、動きが混ざる。影響の強さを調整して、整える
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import bpy

obj = bpy.context.active_object
track = obj.animation_data.nla_tracks.new()
strip = track.strips.new("Walk", 1, bpy.data.actions["WalkAction"])
```
