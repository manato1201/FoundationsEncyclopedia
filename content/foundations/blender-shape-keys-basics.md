## 概要

シェイプキーは、メッシュの**形の変化を複数保存**して、スライダーで混ぜ合わせる機能。笑顔・怒り・まばたきなどの表情を作るときによく使う。ほかのDCCツールでは、ブレンドシェイプ(モーフターゲット)とも呼ばれる。

## 基礎文法

| 要素           | 役割                                   |
| -------------- | -------------------------------------- |
| Basis          | 基準になる元の形                       |
| キー           | 基準から変形した形の記録               |
| 値(スライダー) | 0で基準の形、1で変形した形。間は混ざる |

## つまずきやすい点

- 頂点の数や順序を変える編集(追加・削除など)をすると、シェイプキーとの対応が崩れる場合がある。シェイプキーを作る前に、形を確定させる
- 値を1より大きくしたり、0より小さくしたりすると、さらに強調された形になる。意図しないときは、範囲を制限する
- 複数のキーを同時に使うと、変形が重なる。重ねたときの見え方を確認する

## 実装例(コード)

```python
import bpy

obj = bpy.context.active_object
obj.shape_key_add(name="Basis")             # 基準の形
smile = obj.shape_key_add(name="Smile")     # 新しいキー
smile.value = 0.5                           # 半分だけ適用する
```
