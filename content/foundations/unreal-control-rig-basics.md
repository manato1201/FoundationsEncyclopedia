## 概要

Control Rigは、Unreal Engineの中で、**リグ(骨の操作装置)を作って使う**ための機能。DCCツール(Mayaなど)に戻らずに、エンジンの中で、ポーズをつけたりアニメーションを作ったりできる。

## 基礎文法

| 要素         | 役割                                   |
| ------------ | -------------------------------------- |
| Control Rig  | リグを組む、グラフ付きのアセット       |
| コントロール | アニメーターが動かす、操作用の部品     |
| リググラフ   | コントロールとボーンの関係を作るグラフ |
| Sequencer    | 時間に沿って、コントロールにキーを打つ |

## つまずきやすい点

- 作る前に、対象のスケルトンの階層(ボーンの構造)を確認する。名前や構造が違うと、結びつけがうまくいかない
- 複雑なリグは、評価の負荷が大きくなる場合がある。ゲーム内の実行で使うなら、負荷を確認する
- 機能の名前や使い方は、エンジンのバージョンで変わる場合がある。使っている版のドキュメントで確認する
