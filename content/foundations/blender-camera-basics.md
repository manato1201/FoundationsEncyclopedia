## 概要

**カメラ**の見え方は、位置・向き・**焦点距離**で決まる。焦点距離が小さいほど広く映り(広角)、大きいほど狭く、遠くが大きく見える(望遠)。構図は、カメラビューで確認する。

## 基礎文法

| 設定 | 意味 |
| --- | --- |
| 焦点距離 | 画角を決める。小さいと広角 |
| 解像度 | 書き出す画像の大きさ |
| クリップ | 映る範囲の、手前と奥の限界 |

## つまずきやすい点

- カメラが映す範囲の外にあるものは、レンダリングされない。カメラビューで確認する
- クリップの範囲が狭いと、近いものや遠いものが、切れて見える
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import bpy

cam_data = bpy.data.cameras.new("Cam")
cam_data.lens = 50  # 焦点距離(mm)
cam = bpy.data.objects.new("Cam", cam_data)
bpy.context.collection.objects.link(cam)
```
