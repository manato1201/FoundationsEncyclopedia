## 概要

**マルチカットツール**は、ポリゴンの辺や面を、自由に切るためのツール。辺の分割、エッジループの挿入、面を横切る切り込みなどを、1つのツールで行える。形の流れ(トポロジー)を整えるときによく使う。

## 基礎文法

| 使い方 | 内容 |
| --- | --- |
| 辺の分割 | 辺の上に点を追加する |
| 面を切る | 面の中を通る辺を作る |
| ループの挿入 | 一周する辺の流れを追加する |

## つまずきやすい点

- 切りすぎると、不要な辺が増え、あとの編集が大変になる。必要な箇所に絞る
- 三角形や5角形以上の面ができやすい。形の流れに影響がないかを確認する
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import maya.cmds as cmds

# 辺のループを挿入する例(オプションは版で異なる場合がある)
cmds.polySplitRing("pCube1.e[0]", divisions=1)
```
