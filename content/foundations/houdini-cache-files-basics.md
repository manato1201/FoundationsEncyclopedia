## 概要

**キャッシュ**は、重い計算の結果を、**ファイルに保存して使い回す**こと。Houdiniでは**File Cache**ノードを使う。シミュレーションなどの計算を毎回やり直さずに済み、確認や後の作業が速くなる。

## 基礎文法

| 操作 | 役割 |
| --- | --- |
| 書き出し | 結果をファイルに保存する |
| 読み込み | 保存したファイルから、結果を使う |

## つまずきやすい点

- 上流の設定を変えたのに、キャッシュを更新し忘れると、古い結果が使われ続ける
- 保存先の容量に注意する。シミュレーションのキャッシュは、大きくなりやすい
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import hou

geo = hou.node("/obj").createNode("geo")
cache = geo.createNode("filecache")  # 計算結果を保存・読み込みするノード
```
