## 概要

**ベイク**は、コンストレイントやシミュレーションなど、計算で動いていたものを、**毎フレームのキーフレーム**に書き出して固定すること。ほかのソフトやゲームエンジンへ渡すときに使う。

## 基礎文法

| 用途 | 例 |
| --- | --- |
| 別のソフトへ渡す | リグの動きを、キーだけにして書き出す |
| シミュレーションの固定 | 計算結果を、キーとして残す |

## つまずきやすい点

- キーが毎フレーム入るので、データが増え、編集しにくくなる。ベイクは、最後の段階で行う
- ベイクの前に、元のデータを保存しておく。やり直せなくなる場合がある
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import maya.cmds as cmds

cmds.bakeResults("pSphere1", time=(1, 48), simulation=True)  # 1〜48フレームをキーにする
```
