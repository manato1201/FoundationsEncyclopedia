## 概要

PHPは、Webページを動的に生成するために設計されたサーバーサイドスクリプト言語。HTMLファイルの中に`<?php ... ?>`タグで直接コードを埋め込める点が大きな特徴で、WordPressをはじめ多くのCMS・Webアプリケーションの基盤として使われている。

## 基礎文法

```php
<?php
$name = "World"; // 変数には$記号を付ける
$items = ["Sort", "Search", "Tree"];

foreach ($items as $item) {
    echo "アイテム: {$item}\n"; // 文字列内での変数展開({}で囲む)
}

function greet(string $name): string {
    return "こんにちは、{$name}さん";
}
?>
<h1><?= greet($name) ?></h1>
```

- `<?= ... ?>`は`<?php echo ...; ?>`の短縮記法

## つまずきやすい点

- 変数のスコープはデフォルトで関数内に閉じており、グローバル変数を関数内で使うには`global`キーワードでの明示が必要。他言語のようにブロックスコープではなく関数スコープである点に注意
- PHPは緩やかな型付けの言語で、`==`(緩やかな比較)と`===`(厳密な比較)の挙動が大きく異なる。`0 == "abc"`のような直感に反する比較結果(PHPのバージョンによって挙動が変わった経緯もある)でバグを生みやすいため、`===`を基本に使うことが推奨される
- HTMLとPHPコードが同じファイルに混在しやすいため、ロジックとテンプレート(表示)の分離を意識しないと、保守性の低いコードになりがち。Laravel等のフレームワークはテンプレートエンジン(Blade等)でこの分離を促す設計になっている

## 実装例(コード)

```php
<?php
declare(strict_types=1); // 型の厳密なチェックを有効化する宣言

function add(int $a, int $b): int {
    return $a + $b;
}
```
