## 概要

**モーションパス**は、**曲線に沿って**オブジェクトを動かす機能。カメラの移動、乗り物の走行、飛ぶ物体の軌道などを作れる。曲線の形を変えると、動きの軌道も変わる。

## 基礎文法

| 設定 | 意味 |
| --- | --- |
| カーブ | 動きの道筋 |
| フォロー | 進行方向に向きを合わせる |
| パスの値 | カーブ上の位置(開始から終了) |

## つまずきやすい点

- カーブの向き(始点と終点)が逆だと、反対方向へ進む
- カーブの形を変えると、動きの速さも変わって見える。再生して確認する
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import maya.cmds as cmds

cmds.pathAnimation("camera1", curve="curve1", follow=True)  # カーブに沿って動かす
```
