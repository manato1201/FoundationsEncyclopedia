## 概要

**メッセージキュー**は、送る側と受け取る側の間に置く、メッセージの待ち行列。送る側は、処理の完了を待たずに次へ進める。受け取る側は、自分の処理能力に合わせて取り出せるので、急にアクセスが増えても、全体が止まりにくい。

## 基礎文法

| 用語 | 意味 |
| --- | --- |
| プロデューサー | メッセージを送る側 |
| コンシューマー | メッセージを受け取って処理する側 |
| デッドレターキュー | 何度失敗しても処理できないメッセージの置き場 |

## つまずきやすい点

- 同じメッセージが、複数回届く場合がある(少なくとも1回の配信)。処理は、何度実行しても結果が同じになる(冪等な)ようにする
- 順序が保証されない種類のキューがある。順序が大切な処理では、仕様を確認する
- 溜まる一方になっていないかを、キューの長さで監視する

## 実装例(コード)

```python
# 擬似コード
queue.send({"task": "send_mail", "to": "user@example.com"})  # 送る側

message = queue.receive()   # 受け取る側
send_mail(message["to"])
queue.delete(message)       # 完了したら消す
```
