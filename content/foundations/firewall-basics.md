## 概要

**ファイアウォール**は、ネットワークを通る通信を、決めたルールに照らして、通すか止めるかを判断する仕組み。外からの不要なアクセスを防ぐ、内側から外への通信を制限する、といった目的で使う。

## 基礎文法

| ルールの要素 | 例 |
| --- | --- |
| 送り元・宛先 | 特定のIPアドレスの範囲 |
| ポート | 80(HTTP)・443(HTTPS)・22(SSH) |
| 動作 | 許可 / 拒否 |

## つまずきやすい点

- 必要のないポートを開けたままにしない。使うものだけを許可する(最小権限)
- ルールの順序で、結果が変わる場合がある。上から順に評価され、最初に合ったものが使われる製品が多い
- ファイアウォールを設定しても、アプリ自身の脆弱性は防げない。ほかの対策と組み合わせる

## 実装例(コード)

```bash
# Linux(ufw)の例: SSHとHTTPSだけを許可して、有効にする
sudo ufw allow 22/tcp
sudo ufw allow 443/tcp
sudo ufw enable
```
