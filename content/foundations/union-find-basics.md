## 概要

**Union-Find**(素集合データ構造)は、要素をグループに分けて管理する。「この2つは同じグループか」の判定(find)と、「2つのグループを1つにする」操作(union)を、非常に速く行える。ネットワークのつながりや、閉路の検出に使う。

## 基礎文法

| 操作 | 意味 |
| --- | --- |
| find(x) | xの属するグループの代表を返す |
| union(a, b) | aとbのグループを合体する |
| 経路圧縮 | findのときに、親のつなぎ方を短くする工夫 |

## つまずきやすい点

- 経路圧縮と、小さい木を大きい木につなぐ工夫(サイズ・ランクによる併合)を組み合わせると、ほぼ定数の時間になる
- グループを分割する操作は、基本的にできない。合体だけを扱う
- 代表は、合体のたびに変わる場合がある。代表の値そのものに意味を持たせない

## 実装例(コード)

```python
parent = list(range(10))

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]  # 経路を圧縮する
        x = parent[x]
    return x

def union(a, b):
    parent[find(a)] = find(b)
```
