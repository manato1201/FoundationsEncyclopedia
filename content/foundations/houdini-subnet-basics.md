## 概要

Houdiniのネットワークは、作業が進むとノードが増え、見通しが悪くなる。そのとき、まとまった機能をもつノードの束を、**サブネット**(Subnetwork)という1つのノードにしまうと、全体が読みやすくなる。サブネットの中は、通常のネットワークと同じで、中にまた、サブネットを作ることもできる。

## 基礎文法

| 操作 | 方法 |
| --- | --- |
| まとめる | ノードを選んで Collapse(Shift+C) |
| 中に入る / 出る | i キー / u キー |
| 展開する(元に戻す) | サブネットの中身を外へ取り出す操作(メニューの名称は版による) |
| 部品に育てる | サブネットから HDA を作る([HDAの基礎](/foundations/houdini-hda-basics)) |

- サブネットの外側から見えるのは、入力・出力・公開したパラメーターだけ
- 入力の数や名前は、まとめるときのつなぎ方で決まる。必要なら後から整える
- ノードを探しやすい名前に変えておくと、あとで見直しやすい

## つまずきやすい点

- まとめたあとに、外へ出した入出力の順序が入れ替わって、つなぎ先がずれることがある。まとめたあとに、結果を目で確認する
- サブネット内のノードの値は、外から直接は変えられない。頻繁に触る値は、パラメーターとして外へ出す
- サブネットにしただけでは、他のシーンで再利用できない。使い回すには、HDAにする
- 名前や操作の場所は、版によって違う場合がある

## 実装例(コード)

```python
import hou

geo = hou.node("/obj").createNode("geo", "demo")
box = geo.createNode("box")
xform = geo.createNode("xform")
xform.setInput(0, box)

# 2つのノードを、1つのサブネットにまとめる
subnet = geo.collapseIntoSubnet((box, xform), "box_and_move")
print(subnet.path())     # /obj/demo/box_and_move
```
