## 概要

テクスチャペイントは、3Dモデルの表面に**直接ブラシで色を塗り**、その結果をテクスチャ画像として作る機能。UV展開された面が、画像の上のどこに対応するかをもとにして塗られる。

## 基礎文法

| 要素           | 役割                               |
| -------------- | ---------------------------------- |
| UV             | 3Dモデルの表面と、画像の位置の対応 |
| テクスチャ画像 | 塗った結果を記録する画像           |
| ブラシ         | 色・大きさ・強さを持つ描画の道具   |

## つまずきやすい点

- 描いた画像は、**保存しなければ失われる**。ブレンドファイルとは別に、画像を保存する
- UVが重なっていたり、小さすぎたりすると、塗った結果が意図しない場所に出る、または粗くなる
- 画像の解像度が低いと、拡大したときにぼやける。必要な解像度で作る

## 実装例(コード)

```python
import bpy

image = bpy.data.images.new("PaintTexture", width=2048, height=2048)  # 塗るための画像を作る
image.filepath_raw = "//paint_texture.png"
image.file_format = "PNG"
image.save()  # 塗ったあとで保存する
```
