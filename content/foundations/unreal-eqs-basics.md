## 概要

**EQS**(Environment Query System)は、AIが**周囲の場所を評価して、最適な位置を選ぶ**仕組み。候補の点を作り、距離や見通しなどの条件でテストして点数を付ける。「プレイヤーから隠れられる場所へ移動する」といった行動を作れる。

## 基礎文法

| 要素 | 役割 |
| --- | --- |
| ジェネレーター | 候補の点を作る |
| テスト | 条件で点を評価する |
| コンテキスト | 評価の基準になる対象(プレイヤーなど) |

## つまずきやすい点

- 候補の点が多いと、計算が重くなる。範囲と数を絞る
- テストの重みの付け方で、結果が変わる。ゲームの狙いに合わせて調整する
- 名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```text
# 流れ
ジェネレーターで候補を作る → テストで評価 → 最高点の位置へ移動する
```
