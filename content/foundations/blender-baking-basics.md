## 概要

**ベイク**は、光の当たり方や、細かい形の凹凸などの情報を、**テクスチャ画像に焼き込む**こと。リアルタイムで動かすゲームなどで、重い計算を事前に済ませるために使う。

## 基礎文法

| 種類 | 焼き込む内容 |
| --- | --- |
| 拡散(Diffuse) | 色の情報 |
| 法線(Normal) | 細かい凹凸の向き |
| アンビエントオクルージョン | 隙間の暗さ |

## つまずきやすい点

- UVが重なっていたり、はみ出していたりすると、結果が壊れる
- 画像を保存しないと、ベイクの結果は失われる
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import bpy

bpy.context.scene.render.engine = "CYCLES"  # ベイクはCyclesで行う
bpy.ops.object.bake(type="DIFFUSE")
```
