## 概要

分類のモデルの良さは、**正解率**だけでは分からない。たとえば、病気の人が1%しかいないとき、「全員、健康」と答えるだけでも正解率は99%になる。そこで、**適合率**(誤検出の少なさ)と**再現率**(見逃しの少なさ)も見る。

## 基礎文法

| 指標 | 意味 | 式 |
| --- | --- | --- |
| 正解率 | 全体のうち、当たった割合 | (TP + TN) / 全体 |
| 適合率 | 陽性と予測したうち、本当に陽性だった割合 | TP / (TP + FP) |
| 再現率 | 実際の陽性のうち、見つけた割合 | TP / (TP + FN) |

## つまずきやすい点

- 適合率と再現率は、一方を上げると、他方が下がりやすい。目的に合わせて、釣り合いを決める
- データの偏りが大きいときは、正解率だけで判断しない
- 評価は、学習に使っていない別のデータで行う。同じデータで評価すると、良く見えすぎる

## 実装例(コード)

```python
tp, fp, fn = 8, 2, 4
precision = tp / (tp + fp)   # 0.8
recall = tp / (tp + fn)      # 約0.67
print(precision, recall)
```
