## 概要

Blenderは、いまの作業の種類に応じて「モード」を切り替えて使う。基本は2つ。**オブジェクトモード**は、シーンの中の物(オブジェクト)を配置する。**編集モード**は、選んだオブジェクトの形そのものを、頂点・辺・面の単位で変える。同じ`G`(移動)でも、どのモードで押したかで、動く対象が違う。

## 基礎文法

| モード | 操作の対象 | 主な用途 |
| --- | --- | --- |
| オブジェクトモード | オブジェクト全体 | 配置・親子付け・モディファイアの追加 |
| 編集モード | 頂点・辺・面 | モデリング(押し出し・ループカットなど) |

- Tab: オブジェクトモード ↔ 編集モード
- 編集モード内: 1=頂点、2=辺、3=面の選択モード
- メッシュ以外(カーブなど)は、編集モードで編集できる要素が変わる

## つまずきやすい点

- 編集モードで拡大したつもりが、見た目は変わらない、または形が崩れたときは、選択している要素が違うことが多い。いまのモードと選択を確認する
- 編集モードの変更は、オブジェクトモードへ戻ったときに確定される(メッシュデータに反映される)。Pythonで頂点を読むときも、編集モードのままだと、古い値が見えることがある
- 複数のオブジェクトを選んでTabを押すと、すべてを同時に編集モードにできる(マルチオブジェクト編集)。意図せず別のオブジェクトを変えないように、選択を確認する
- オブジェクトモードでスケールを変えたあと、編集モードでの寸法がずれて見えるときは、[トランスフォームの適用](/foundations/blender-apply-transform-basics)を検討する

## 実装例(コード)

```python
import bpy

obj = bpy.context.active_object            # 選択中(アクティブ)のオブジェクト
bpy.ops.object.mode_set(mode="EDIT")       # 編集モードへ
bpy.ops.mesh.select_mode(type="VERT")      # 頂点の選択モード
bpy.ops.object.mode_set(mode="OBJECT")     # オブジェクトモードへ戻る
print(obj.mode)                            # "OBJECT"
```
