## 概要

Goは静的型付け言語だが、`var`による明示的な宣言に加え、`:=`という短縮代入演算子で型推論を伴う変数宣言ができる。この`:=`はGo特有の記法で、関数内でのみ使え、パッケージレベル(関数の外)では使えないという制約がある。

## 基礎文法

```go
var score int = 100    // 明示的な型宣言
var name string = "Player"
var isActive bool = true

count := 10              // :=による短縮宣言(型推論、関数内でのみ使用可)
message := "Hello"

const MaxHp = 100         // 定数(再代入不可)
```

## つまずきやすい点

- Goでは宣言したのに使わない変数(未使用変数)はコンパイルエラーになる。C#やJavaでは警告止まりのことが多いこの挙動は、Go特有の「厳格さ」の1つであり、デバッグ用に一時的に追加した変数の消し忘れにすぐ気づける反面、初学者は最初戸惑うことが多い
- Goには「ゼロ値」という概念があり、明示的に初期化しなかった変数は型に応じたデフォルト値(数値なら0、文字列なら空文字、boolならfalse)で自動的に初期化される。C++のように「初期化しないと不定な値」ということはなく、常に予測可能な初期状態を持つ
- `:=`は「新しい変数の宣言」を意味するため、既に宣言済みの変数に対して使うとコンパイルエラーになる(ただし、複数代入の一部が新規変数であれば許容される)。`var`との使い分けを誤ると、意図せず新しい変数を作ってしまい、外側のスコープの変数が更新されないバグにつながることがある

## 実装例(コード)

```go
// ゼロ値の確認
var count int    // 0
var name string   // ""
var active bool    // false
fmt.Println(count, name, active)
```
