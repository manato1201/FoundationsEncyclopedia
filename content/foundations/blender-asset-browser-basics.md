## 概要

**アセットブラウザ**は、モデルやマテリアルなどを**アセットとして登録**し、一覧から探して、ドラッグで使い回せる機能。よく使う部品を整理して、制作を速くできる。

## 基礎文法

| 操作 | 役割 |
| --- | --- |
| アセットとしてマーク | 検索できる状態にする |
| ライブラリ | アセットを保存した場所 |

## つまずきやすい点

- 登録しただけでは、別のファイルから見えない。ライブラリとして登録した場所に保存する
- 名前やタグを付けておくと、あとから探しやすい
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import bpy

obj = bpy.context.active_object
obj.asset_mark()  # アセットとして登録する
```
