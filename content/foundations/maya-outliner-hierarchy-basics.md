## 概要

Mayaのオブジェクトは、**親子関係**(階層)を持てる。親を動かすと、子も一緒に動く。**アウトライナ**は、その階層を一覧で見て、整理する画面。名前を整えておくと、大きなシーンでも、目的のものを探しやすい。

## 基礎文法

| 用語 | 意味 |
| --- | --- |
| 親 | 上位のオブジェクト。動くと子も動く |
| 子 | 親に従って動くオブジェクト |
| グループ | 複数のオブジェクトをまとめる入れ物 |

## つまずきやすい点

- 親の位置・回転・拡大は、子に影響する。子の値は、親から見た相対の値になる
- 名前に、`pCube1` のような初期の名前が残ると、分かりにくい。役割が分かる名前に変える
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import maya.cmds as cmds

cmds.parent("wheel", "car")        # wheelをcarの子にする
cmds.group("wheelL", "wheelR", name="wheels")  # まとめてグループにする
```
