## 概要

ゲームの計算は、位置・速度・向きをベクトル(大きさと向きを持つ量)で表すことから始まる。難しい数学は必要なく、使う道具は少ない。足し算(動かす)、スカラー倍(速さを変える)、長さ(距離)、正規化(向きだけ取り出す)、内積(向きの近さ)。これらは、Unity・Unrealなど、どのゲームエンジンでも名前を変えて用意されている。

## 基礎文法

| 計算 | 式(2D) | 使いどころ |
| --- | --- | --- |
| 足し算 | (ax+bx, ay+by) | 位置に速度を足して動かす |
| スカラー倍 | (k·x, k·y) | 速さを変える、デルタタイムを掛ける |
| 長さ | √(x²+y²) | 2点間の距離(差のベクトルの長さ) |
| 正規化 | v / 長さ | 向きだけを取り出す |
| 内積 | ax·bx + ay·by | 向きの近さ、視野内か、前か後ろか |

- 3Dで、2つのベクトルに垂直な向きを求めるには、外積を使う(法線や回転軸の計算)
- 時間の刻みを掛ける考え方は[デルタタイムの基礎](/foundations/delta-time-basics)を参照

## つまずきやすい点

- 長さが0のベクトルを正規化すると、0で割ってしまう。多くのエンジンは0ベクトルを返すが、自作するときは、先に長さを確かめる
- 斜め入力の移動が速くなるのは、(1, 1)の長さが約1.41になるため。入力ベクトルを正規化してから速さを掛ける
- 内積が角度そのものではないこと。角度が要るときは、正規化したうえで`acos`を使う。「前にいるか」だけなら、内積の符号を見るだけでよい
- 距離を比べるだけなら、平方根を取らず、長さの2乗どうしを比べると速い

## 実装例(コード)

```python
import math

def length(v):
    return math.hypot(v[0], v[1])

def normalize(v):
    n = length(v)
    return (0.0, 0.0) if n == 0 else (v[0] / n, v[1] / n)

def dot(a, b):
    return a[0] * b[0] + a[1] * b[1]

player = (0.0, 0.0)
enemy = (3.0, 4.0)
facing = (1.0, 0.0)                       # プレイヤーが向いている方向(長さ1)

to_enemy = (enemy[0] - player[0], enemy[1] - player[1])
print(length(to_enemy))                   # 5.0(距離)
print(dot(facing, normalize(to_enemy)))   # 0.6(正なので、おおむね前方にいる)
```
