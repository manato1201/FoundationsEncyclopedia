## 概要

ジオメトリスプレッドシートは、Houdiniでジオメトリの中身を**表**として確認する画面。点・面などの要素が、どんな値(**アトリビュート**)を持っているかを、数値で確かめられる。見た目だけでは分からない問題を調べるときに役立つ。

## 基礎文法

| 要素                     | 内容                    |
| ------------------------ | ----------------------- |
| 点(Points)               | 位置 P などの値を持つ   |
| 頂点(Vertices)           | 面ごとの点の使われ方    |
| プリミティブ(Primitives) | 面や曲線などの単位      |
| ディテール(Detail)       | ジオメトリ全体で1つの値 |

## つまずきやすい点

- どのノードの出力を見ているかで、表示される内容が変わる。確認したいノードを選んでいるかを確認する
- アトリビュートの名前は、大文字小文字を区別する(`P` と `p` は別)
- 要素が多いと、表が長くなる。並べ替えや、見たい行への絞り込みを使う

## 実装例(コード)

```python
import hou

geo = hou.node("/obj/my_geo/box1").geometry()
for point in geo.points()[:3]:
    print(point.number(), point.position())  # 表に表示される位置の値を、Pythonから読む
```
