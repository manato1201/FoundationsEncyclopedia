## 概要

**tmux**は、端末を**多重化**するツール。1つの端末の中に複数の画面を持てて、SSHの接続が切れても、セッションの中の処理は動き続ける。サーバーでの長い作業に便利。

## 基礎文法

| 操作 | キー・コマンド |
| --- | --- |
| 新しいセッション | `tmux new -s 名前` |
| デタッチ | `Ctrl+b` を押してから `d` |
| アタッチ | `tmux attach -t 名前` |
| 一覧 | `tmux ls` |

## つまずきやすい点

- 操作の始まりは、プレフィックスキー(既定は `Ctrl+b`)。押してから、続けて次のキーを押す
- セッションを閉じる(終了する)と、中の処理も止まる。離れるときは、デタッチを使う
- サーバーを再起動すると、セッションは消える

## 実装例(コード)

```bash
tmux new -s work     # 作業用のセッションを作る
# 作業して、Ctrl+b → d で離れる
tmux attach -t work  # あとで戻る
```
