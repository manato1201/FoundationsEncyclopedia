## 概要

**オブザーバビリティ(可観測性)**は、システムの外に出る情報から、内部で何が起きているかを把握できる度合い。主に、次の3種類の情報を使う。

| 種類 | 内容 | 例 |
| --- | --- | --- |
| ログ | 出来事の記録 | 「ユーザーID 5 の決済に失敗した」 |
| メトリクス | 時間ごとの数値 | エラー率、応答時間、CPU使用率 |
| トレース | 1つのリクエストの流れ | ゲートウェイ → 注文 → 決済の各所要時間 |

## 基礎文法

3つは、使う場面が違う。

| 知りたいこと | 向く情報 |
| --- | --- |
| 異常が起きているか | メトリクス |
| どこで時間がかかっているか | トレース |
| 何が起きたか(詳細) | ログ |

## つまずきやすい点

- ログを増やせば良いわけではない。量が多すぎると、必要な情報が見つからず、保存の費用も増える。見る目的に合う情報だけを出す
- 個人情報やパスワードなどを、ログに出してはならない。出力する内容を決めておく
- 3つを別々に見るだけでなく、同じ識別子(リクエストIDなど)で結びつけると、調べやすくなる

## 実装例(コード)

```python
import logging

logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s request_id=%(request_id)s %(message)s")
# 同じ request_id をログとトレースに付けると、結びつけて調べられる
```
