## 概要

**ソフト選択**は、選んだ頂点の周囲にも、**距離に応じた弱い影響**を与える機能。頂点を1つ動かすと、周囲が滑らかに追従して、粘土をつまむような変形ができる。

## 基礎文法

| 設定 | 意味 |
| --- | --- |
| 減衰の距離 | 影響が及ぶ範囲 |
| 減衰の形 | 距離による影響の弱まり方 |

## つまずきやすい点

- 範囲が広すぎると、意図しない場所まで動く。小さな範囲から試す
- 作業が終わったら、ソフト選択をオフに戻す。残っていると、ほかの操作に影響する
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import maya.cmds as cmds

cmds.softSelect(softSelectEnabled=True, softSelectDistance=2.0)  # ソフト選択をオンにして、範囲を指定する
```
