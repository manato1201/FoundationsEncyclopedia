## 概要

Houdiniでは、パラメーターに**式**を書ける。たとえば、フレーム番号 `$F` を使うと、時間で値が変わる。`ch("../ctrl/size")` のように、**ほかのパラメーターを参照**すると、1つの値で、複数のノードを連動させられる。

## 基礎文法

| 書き方 | 意味 |
| --- | --- |
| `$F` | 現在のフレーム番号 |
| `ch("パス")` | 別のパラメーターの値を読む |
| `sin($F)` | 数学の関数も使える |

## つまずきやすい点

- 参照のパスが正しくないと、エラーになる。相対パス(`../`)で書くと、ノードを移動しても壊れにくい
- 式が複雑になるほど、読み解きにくい。分かりやすい名前のコントロールにまとめる
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import hou

parm = hou.parm("/obj/geo1/box1/sizex")
parm.setExpression("$F * 0.1")  # フレームに応じて大きくする
```
