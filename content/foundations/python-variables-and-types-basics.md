## 概要

Pythonは「動的型付け」言語で、[C#の変数宣言と型の基礎](/foundations/csharp-variables-and-types-basics)のように型を明示する必要がない。変数は単なる「値への名札」のようなもので、同じ変数名に後から異なる型の値を再代入することもできる。

## 基礎文法

```python
score = 100          # int型として扱われる
name = "Player"      # str型
is_active = True     # bool型

score = "100点"       # 同じ変数に別の型を再代入できる(動的型付け)

# 型ヒント(Python 3.5以降): 型を明示できるが、実行時には強制されない
count: int = 10
```

- 型ヒント(`count: int`)はエディタやmypyのような静的解析ツールが読むためのものであり、実行時にPython自体がこの型を強制するわけではない

## つまずきやすい点

- 「型がない」わけではなく、「変数に型の縛りがない」だけで、値そのものは常に型を持つ(`type(score)`で確認できる)。「動的型付け=型がない」という誤解をしやすいが、正確には「変数と型の結びつきが緩い」というのが実態
- 型ヒントを書いても、実行時に間違った型を代入するコードはエラーにならずそのまま実行されてしまう。型の誤りを実行前に検出したい場合は、mypyのような別の静的解析ツールをCI等に組み込む必要がある
- 複数の変数が同じ値を指す場合(`a = b = [1, 2, 3]`)、一方を変更すると他方にも影響することがある(ミュータブルなオブジェクトの場合)。C#の参照型・値型の区別と同様の注意が必要になる

## 実装例(コード)

```python
# ミュータブル(リスト)とイミュータブル(整数)の挙動の違い
a = [1, 2, 3]
b = a
b.append(4)
print(a)  # [1, 2, 3, 4] (aも変更されている、同じリストを指しているため)

x = 10
y = x
y += 1
print(x)  # 10 (xは変わらない、整数はイミュータブル)
```
