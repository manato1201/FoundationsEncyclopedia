## 概要

**依存性の注入**(Dependency Injection)は、クラスが使う部品(依存)を、クラスの中で作らず、**外から渡してもらう**設計。部品の差し替えやテストがしやすくなり、クラスどうしの結びつきが弱くなる。

## 基礎文法

| 書き方 | 特徴 |
| --- | --- |
| 中で作る | 具体的な部品に固定される。テストしにくい |
| 外から渡す(DI) | 差し替えやすい。テストしやすい |

## つまずきやすい点

- フレームワークのDIコンテナを使わなくても、コンストラクタで渡すだけでDIになる
- 何でもインターフェースにすると、複雑になる。差し替える必要がある部分に絞る
- 依存が多すぎるクラスは、責務が多すぎるサイン。分割を検討する

## 実装例(コード)

```python
class OrderService:
    def __init__(self, mailer):   # 外から受け取る
        self.mailer = mailer

    def complete(self, order):
        self.mailer.send(order.email, "ご注文ありがとうございます")

service = OrderService(RealMailer())      # 本番
# テストでは FakeMailer() を渡す
```
