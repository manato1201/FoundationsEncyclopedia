## 概要

**ダイクストラ法**は、辺に**負でない重み**(距離や時間)があるグラフで、出発点から各点までの最短の距離を求めるアルゴリズム。道路の経路探索の基本になる。優先度付きキュー(ヒープ)で、次に確定する点を効率よく選ぶ。

## 基礎文法

| 方法 | 辺の重み | 用途 |
| --- | --- | --- |
| 幅優先探索 | すべて同じ(辺の数) | 辺の数で最短 |
| ダイクストラ法 | 負でない | 重み付きの最短経路 |
| ベルマンフォード法 | 負もよい | 負の辺があるとき |

## つまずきやすい点

- 辺の重みに**負の値**があると、正しく動かない。負の辺があるときは、別の方法を使う
- 優先度付きキューを使わない単純な実装は、点の数の2乗の時間がかかる
- 最短の経路そのものがほしいときは、各点の「直前の点」も記録しておく

## 実装例(コード)

```python
import heapq

def dijkstra(graph, start):
    dist = {start: 0}
    heap = [(0, start)]
    while heap:
        d, node = heapq.heappop(heap)
        if d > dist.get(node, float('inf')):
            continue
        for nxt, w in graph[node]:
            nd = d + w
            if nd < dist.get(nxt, float('inf')):
                dist[nxt] = nd
                heapq.heappush(heap, (nd, nxt))
    return dist
```
