## 概要

**アニメーションイベント**は、アニメーションクリップの**特定の時点**で、スクリプトの関数を呼び出す機能。攻撃のアニメーションの、振り下ろした瞬間にダメージを与える、足が着いた瞬間に足音を鳴らす、といった同期に使う。

## 基礎文法

| 要素 | 役割 |
| --- | --- |
| イベント | クリップの特定の時刻に付ける印 |
| 関数名 | 呼び出すスクリプトの関数 |

## つまずきやすい点

- 呼び出される関数は、アニメーターと同じオブジェクトのスクリプトにある必要がある
- 関数名を変更すると、イベントの指定が合わなくなり、エラーになる
- 名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```csharp
using UnityEngine;

public class FootSteps : MonoBehaviour
{
    // アニメーションイベントから呼ばれる
    public void OnFootstep()
    {
        Debug.Log("足音を鳴らす");
    }
}
```
