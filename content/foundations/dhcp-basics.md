## 概要

DHCP(Dynamic Host Configuration Protocol)は、ネットワークにつながった機器へ、IPアドレスなどの設定を自動で割り当てる仕組み。家庭のルーターは、DHCPサーバーの役割を持つことが多い。手で設定する手間と、アドレスの重複を避けられる。

## 基礎文法

やり取りは4つの段階で行われ、頭文字から「DORA」と呼ばれることがある。

| 段階 | 向き | 意味 |
| --- | --- | --- |
| Discover | 機器 → サーバー | 設定を探す |
| Offer | サーバー → 機器 | 貸し出す設定を提案する |
| Request | 機器 → サーバー | 提案された設定を使いたいと伝える |
| Ack | サーバー → 機器 | 貸し出しを確定する |

## つまずきやすい点

- 貸し出されるアドレスには**期限(リース)**がある。同じ機器でも、期限が切れるとアドレスが変わることがある
- サーバーなどアドレスを変えたくない機器には、固定のIPアドレスを手で設定するか、DHCPの予約機能を使う
- 同じネットワークにDHCPサーバーが複数あると、設定が食い違うことがある。1つのネットワークでは、役割を整理しておく

## 実装例(コード)

```bash
# 現在のIPアドレスなどの設定を確認する(Windows)
ipconfig /all
```
