## 概要

シンボル(`:name`のように`:`から始まる)は、文字列に似た「名前を表すオブジェクト」だが、文字列とは異なり同じ名前のシンボルは常に同一のオブジェクトを指す(イミュータブルで、一度作られたら使い回される)。ハッシュのキーやメソッド名の参照など、「値そのものではなく名前・識別子として使いたい」場面で好んで使われる。

## 基礎文法

```ruby
status = :active   # シンボル
name = "active"    # 文字列(見た目の値は同じでも別物)

status.object_id == :active.object_id # true (同じシンボルは常に同一オブジェクト)
name.object_id == "active".object_id  # false (毎回新しい文字列オブジェクトが作られる)

# ハッシュのキーとして頻出
user = { name: "Alice", role: :admin }
```

## つまずきやすい点

- シンボルと文字列は`==`で比較すると常にfalseになる(`:active == "active"`はfalse)。外部から受け取ったデータ(JSON等)は文字列キーになっていることが多く、シンボルキーのハッシュと混同すると値が取得できないバグになりやすい
- シンボルはイミュータブルであり、一度作られると基本的にガベージコレクションされない(Rubyのバージョンによって挙動は異なる)。ユーザー入力のような動的な値を安易に`to_sym`でシンボル化し続けると、メモリを圧迫することがある
- 「文字列より速いから」という理由だけでシンボルを多用すると、意味が異なるものを同じ扱いにしてしまうことがある。あくまで「名前・識別子」として使うのが適切な場面に限定するのがよい

## 実装例(コード)

```ruby
# 文字列キーとシンボルキーが混在するハッシュへの安全なアクセス例
def get_role(user)
  user[:role] || user["role"] || :guest
end
```
