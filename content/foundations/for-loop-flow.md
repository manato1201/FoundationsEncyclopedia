## 概要

`for`ループはほぼ全ての手続き型言語に存在する制御構造で、内部的には「初期化」「条件判定」「本体実行」「更新」という4つのステップが決まった順序で繰り返されている。この繰り返しの仕組みを正しくイメージできると、`while`ループとの使い分けやオフバイワンエラー(境界条件のミス)への理解が深まる。

## 基礎文法

```csharp
for (int i = 0; i < 5; i++) {
    Debug.Log(i);
}
```

1. **初期化**: `int i = 0` — ループに入る前に1回だけ実行される
2. **条件判定**: `i < 5` — 各周回の最初に評価され、falseになったらループを抜ける
3. **本体実行**: `Debug.Log(i)` — 条件がtrueの間だけ実行される
4. **更新**: `i++` — 本体実行の後、次の条件判定の前に実行される

## つまずきやすい点

- 条件判定は「本体実行の前」に行われるため、初期化直後に条件を満たさない場合は本体が一度も実行されない(`while`と同じ「前判定」ループである)
- 境界条件を`<`にすべきか`<=`にすべきかを取り違えると、意図した回数より1回多い・少ない実行になる(オフバイワンエラー)
- 更新式(`i++`)を本体の中に書いてしまう、あるいは書き忘れると、無限ループやループ変数の二重更新につながる
