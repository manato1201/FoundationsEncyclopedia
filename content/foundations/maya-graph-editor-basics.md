## 概要

グラフエディタは、アニメーションを**曲線**として扱う画面。横軸が時間、縦軸が値(位置・回転など)で、キーとキーの間の動きを、曲線の形で調整できる。

## 基礎文法

| 要素         | 意味                                   |
| ------------ | -------------------------------------- |
| キー         | ある時間での値を決める点               |
| 曲線         | キーの間をどう補間するかを表す線       |
| タンジェント | キーでの曲線の傾き。動きの緩急を決める |

## つまずきやすい点

- 曲線の傾きは、速さを表す。傾きが急なところほど速く動く。止めたいところは、傾きを水平にする
- タンジェントの種類(滑らか・直線・階段状など)で、補間のしかたが変わる。動きの目的に合わせて選ぶ
- キーが多すぎると、調整しにくい。大事なポーズのキーに絞ってから、間を調整する

## 実装例(コード)

```python
import maya.cmds as cmds

cmds.setKeyframe("pSphere1", attribute="translateY", time=1, value=0)
cmds.setKeyframe("pSphere1", attribute="translateY", time=24, value=10)
cmds.keyTangent("pSphere1", attribute="translateY", time=(24, 24), inTangentType="flat")
```
