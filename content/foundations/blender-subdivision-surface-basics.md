## 概要

**サブディビジョンサーフェス**は、粗いメッシュを、**滑らかな曲面**に細分化するモディファイア。少ない頂点で作った形が、滑らかに丸められるので、キャラクターや、有機的な形に向く。

## 基礎文法

| 設定 | 意味 |
| --- | --- |
| Levels Viewport | 作業中の画面での、細分化のレベル |
| Render | レンダリング時の、細分化のレベル |

## つまずきやすい点

- レベルを上げすぎると、頂点が急に増え、重くなる
- 形が丸まりすぎるときは、角の近くに、辺を追加して締める
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import bpy

obj = bpy.context.active_object
mod = obj.modifiers.new(name="Subsurf", type="SUBSURF")
mod.levels = 2          # ビューポート
mod.render_levels = 3   # レンダー
```
