## 概要

**ハルシネーション**は、AIが事実と違う内容を、もっともらしい文章で答える現象。存在しない関数名や、実在しない資料を示すこともある。自然な文章で書かれるため、誤りに気づきにくい。

## 基礎文法

| 対策 | 内容 |
| --- | --- |
| 出典で確認 | 公式ドキュメントや一次資料で、事実や数字を確かめる |
| 実行で確認 | コードは実行し、テストを通して挙動を確かめる |
| 根拠を示させる | 資料を渡して、その範囲で答えさせる(RAG)。根拠の箇所も示させる |
| 人が最終確認 | 重要な判断は、人が結果を確認してから採用する |

## つまずきやすい点

- 「もっともらしさ」と「正しさ」は別。文章が自然でも、内容が誤っていることはある
- 資料を渡しても、読み違いは起こる。根拠の箇所を確認できるようにしておく
- 対策をしても、誤りがゼロになるわけではない。誤りが起きる前提で、確認の手順を決めておく

## 実装例(コード)

```python
# AIが書いたコードは、採用の前に必ずテストで確かめる
def test_add():
    assert add(2, 3) == 5

# テストが通らないコードは、説明が自然でも採用しない
```
