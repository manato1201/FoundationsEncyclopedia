## 概要

Mayaの内部データは、全て「依存グラフ(Dependency Graph)」と呼ばれるノードのネットワークとして表現されている。メッシュ・マテリアル・アニメーションカーブといった一見異なる要素も、実際には全て「属性(アトリビュート)を持つノード」であり、それらが接続によってデータの流れを形成している。

## 基礎文法

ノードエディタで確認できる典型的な接続:

```
[polyCube1] --outputMesh--> [pCubeShape1] --inMesh--> [シェーディンググループ]
```

- 各ノードは複数の入力・出力アトリビュートを持つ
- ある属性の値が変わると、そこから接続されている下流のノードへ再計算が伝播していく

## つまずきやすい点

- メニューから見えている「マテリアルを割り当てる」のような操作も、裏側ではノード同士の接続として表現されている。トラブルシューティングの際、UI上の見た目だけでなくノードエディタで実際の接続関係を確認すると、原因を特定しやすくなることがある
- 依存グラフの評価は「必要になったときだけ再計算する」という遅延評価の性質を持つ。この仕組みを理解していないと、「値を変更したのに画面に反映されない」ように見える一時的な状態に戸惑うことがある(多くは再評価のタイミングの問題)
- ノード同士の接続が複雑に絡み合うと、循環参照に近い状態(相互に依存し合うノード)を意図せず作ってしまい、予期しない挙動や警告メッセージが出ることがある

## 実装例(コード)

```python
# Pythonから2つのノードのアトリビュートを直接接続する例
import maya.cmds as cmds

cmds.connectAttr("locator1.translateX", "pCube1.translateX")
```
