## 概要

シェルスクリプトは、ターミナルで打つコマンドをファイルに書いて、まとめて実行できるようにしたもの。バックアップ・ビルド・デプロイなど、繰り返す作業の自動化に使う。パイプやリダイレクト([パイプとリダイレクトの基礎](/foundations/shell-pipes-and-redirects))はそのまま使える。ここでは、Bashを前提にする。

## 基礎文法

```bash
#!/usr/bin/env bash
set -euo pipefail          # エラーで止める・未定義の変数を禁止する

name="${1:-world}"         # 第1引数。なければ "world"
echo "hello, $name"

if [ -f "memo.txt" ]; then
  echo "memo.txt があります"
else
  echo "ありません"
fi

for f in *.txt; do
  echo "処理: $f"
done
```

| 書き方 | 意味 |
| --- | --- |
| `$1` `$2` | 引数 |
| `$?` | 直前のコマンドの終了コード(0が成功) |
| `[ -f x ]` / `[ -d x ]` | ファイルがある / ディレクトリがある |
| `$(コマンド)` | コマンドの出力を、値として取り込む |

## つまずきやすい点

- 代入の`=`の前後に、空白を入れてはいけない(`name = "x"`は、コマンドとして解釈され、エラーになる)
- 変数は`"$var"`と引用符で囲む。囲まないと、空白を含む値や、空の値で、動作が変わる
- `[ ]`の中は、前後に空白が必要(`[ -f "$x" ]`)。空白がないと、エラーになる
- `set -e`を付けないと、途中のコマンドが失敗しても、続きが実行される。破壊的な処理(`rm`など)の前は、特に注意する
- Windowsの改行コード(CRLF)で保存すると、Linuxで正しく動かない。LFで保存する

## 実装例(コード)

```bash
#!/usr/bin/env bash
set -euo pipefail

# 引数のディレクトリにある .log ファイルの行数を数える
dir="${1:-.}"
for f in "$dir"/*.log; do
  [ -e "$f" ] || continue          # 該当ファイルがなければ飛ばす
  echo "$f: $(wc -l < "$f") 行"
done
```
