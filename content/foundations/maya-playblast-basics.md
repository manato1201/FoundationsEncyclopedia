## 概要

Playblastは、ビューポートに表示されている映像を、そのまま動画にして記録する機能。レンダリングよりずっと速く、動きのタイミングやポーズを確認できる。アニメーション制作の途中確認や、共有に向く。

## 基礎文法

| 設定         | 意味                                           |
| ------------ | ---------------------------------------------- |
| 再生範囲     | 動画にするフレームの範囲                       |
| 解像度       | 動画のサイズ                                   |
| 表示する要素 | ビューポートに出すもの(グリッド、UIなど)を選ぶ |

## つまずきやすい点

- Playblastの画質は、ビューポートの表示品質で決まる。最終的な見た目の確認には、レンダリングが必要
- 再生範囲の設定を忘れると、意図したより長い、または短い動画になる
- 出力先やコーデックの設定は、環境によって使えるものが違う。動画が再生できないときは、形式を変えてみる

## 実装例(コード)

```python
import maya.cmds as cmds

cmds.playblast(startTime=1, endTime=48, format="image", filename="preview", forceOverwrite=True, percent=100)
```
