## 概要

**動的計画法**(DP)は、大きな問題を小さな問題に分け、**解いた結果を保存して使い回す**ことで、同じ計算の繰り返しを避ける方法。再帰で書くとO(2のn乗)かかる計算が、保存を使うと、O(n)になる例がある。

## 基礎文法

| 方法 | やり方 |
| --- | --- |
| メモ化(トップダウン) | 再帰で解き、結果を保存する |
| 表を埋める(ボトムアップ) | 小さい問題から順に、表を埋める |

## つまずきやすい点

- 使えるのは、「同じ小さな問題が何度も出る」(重複部分問題)で、「小さな問題の最適解から全体の最適解が作れる」(最適部分構造)場合
- 保存に使うメモリが増える。必要な範囲だけを保持する工夫もある
- 状態の定義(何を表の1マスとするか)を決めるのが、いちばん難しい。小さな例で、手で表を作って確かめる

## 実装例(コード)

```python
def fib(n, memo={}):
    if n <= 1:
        return n
    if n not in memo:
        memo[n] = fib(n - 1, memo) + fib(n - 2, memo)  # 解いた結果を保存する
    return memo[n]
```
