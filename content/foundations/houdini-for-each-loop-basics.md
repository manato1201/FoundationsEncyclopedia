## 概要

**For-Eachループ**は、ジオメトリの**パーツごとに、同じ処理を繰り返す**仕組み。パーツごとに違う値で変形する、個別に配置する、といった処理を、1つのネットワークで作れる。

## 基礎文法

| 繰り返しの単位 | 例 |
| --- | --- |
| ピース | 名前や番号で分けたパーツごと |
| 点 | 1つ1つの点ごと |

## つまずきやすい点

- 繰り返しの数が多いと、処理が重くなる。必要な単位で行う
- ループの中と外で、値の受け渡しの方法が決まっている。使い方を確認する
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```text
# ネットワークの流れ
入力 → For-Each開始 → 処理のノード → For-Each終了 → 出力
```
