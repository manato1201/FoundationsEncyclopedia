## 概要

大量のファイルから目的のものを探すとき、2つのコマンドを使い分ける。**grep**はファイルの中身(文字列)を検索し、**find**はファイルそのものを、名前・種類・更新日などの条件で探す。

## 基礎文法

| コマンド | 探す対象 | 例 |
| --- | --- | --- |
| grep | ファイルの中身 | `grep -rn "TODO" src` |
| find | ファイル(名前・条件) | `find . -name "*.md"` |

grepのよく使うオプション:

| オプション | 意味 |
| --- | --- |
| -r | フォルダの下を再帰的に探す |
| -n | 行番号を表示する |
| -i | 大文字と小文字を区別しない |

## つまずきやすい点

- ワイルドカード(`*.md`)は、シェルに展開されないよう、引用符で囲むと意図どおりに動く
- grepの検索語は、正規表現として扱われる。記号(`.` や `*`)をそのまま探したいときは、`-F`を付けるか、エスケープする
- 巨大なフォルダ(`node_modules` など)を検索すると遅い。除外する指定を付けるか、最初から対象のフォルダを絞る

## 実装例(コード)

```bash
# 拡張子が .md のファイルのうち、「ステップ」を含む行を探す
find . -name "*.md" -print0 | xargs -0 grep -n "ステップ"
```
