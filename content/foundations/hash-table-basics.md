## 概要

ハッシュテーブルは、キーと値のペアを保持し、平均的にO(1)という高速な検索・追加・削除を実現するデータ構造。C#の`Dictionary<TKey, TValue>`、Pythonの`dict`、JavaScriptの`Map`やオブジェクトなど、多くの言語の連想配列の内部実装として使われている。

## 基礎文法

ハッシュテーブルの基本的な仕組み:

1. キーを「ハッシュ関数」に通し、固定範囲の数値(ハッシュ値)に変換する
2. そのハッシュ値を配列のインデックスとして使い、対応するバケットにキーと値を格納する
3. 検索時も同じハッシュ関数でハッシュ値を求め、そのバケットだけを見ればよいため高速

```python
scores = {}
scores["Alice"] = 100  # "Alice"のハッシュ値を計算し、対応するバケットへ格納
print(scores["Alice"])  # 同じくハッシュ値を計算し、そのバケットを直接参照
```

## つまずきやすい点

- 異なるキーが同じハッシュ値になる「衝突」は必ず起きうる。衝突の解決方法(チェイン法: 同じバケットにリストで複数保持する、オープンアドレス法: 別の空きバケットを探す)によって、最悪ケースの計算量やメモリ効率が変わる
- ハッシュ関数の質が悪い(偏った値ばかり生成する)と、多くのキーが同じバケットに集中し、理論上のO(1)から実質的にO(n)に近い性能まで悪化することがある。カスタムのキー型を使う場合、良質なハッシュ関数の実装が重要になる
- ハッシュテーブルは(実装にもよるが)挿入順序を保持しないことが多い。順序を維持したい場合は、`LinkedHashMap`(Java)のような順序保持版のデータ構造を選ぶ必要がある

## 実装例(コード)

```python
# 出現回数のカウントという、ハッシュテーブルの典型的な使い方
def count_occurrences(items: list[str]) -> dict[str, int]:
    counts = {}
    for item in items:
        counts[item] = counts.get(item, 0) + 1
    return counts
```
