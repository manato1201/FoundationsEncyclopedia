## 概要

アルファブレンディングは、ピクセルのアルファ値(不透明度)を使って、これから描画する色(ソース)と既にフレームバッファにある色(デスティネーション)を混ぜ合わせる処理。半透明のオブジェクト(ガラス、エフェクト等)の描画に使われる。

## 基礎文法

一般的な半透明合成(Alpha Blend)の式:

```
最終色 = ソース色 × ソースアルファ + デスティネーション色 × (1 - ソースアルファ)
```

```hlsl
// シェーダー側はソースの色とアルファを出力するだけで、実際の合成はGPUの固定機能(ブレンドステート)が行う
float4 FragMain() : SV_Target {
    return float4(_Color.rgb, _Color.a); // アルファ値を含めて出力
}
```

## つまずきやすい点

- 不透明オブジェクトは深度バッファのおかげでどの順序で描画しても正しく重なるが、半透明オブジェクトは深度テストだけでは正しく合成できず、**奥から手前へ描画する順序**が結果に直結する。順序を誤ると、本来奥にあるはずのオブジェクトが手前に透けて見えるといった破綻が起きる
- 半透明オブジェクト同士が重なる場合、正確なソートは三角形単位で必要になることもあり、オブジェクト単位のソートだけでは限界がある(パーティクルの密集などで顕著)
- 加算合成(Additive Blend、光やエフェクトでよく使われる)はアルファブレンディングとは異なる合成式(単純に色を足し合わせる)であり、描画順序への依存が弱い代わりに、重なった箇所が白飛びしやすいという別の特性を持つ

## 実装例(コード)

```
// 加算合成の式(順序に依存しない)
最終色 = ソース色 × ソースアルファ + デスティネーション色
```
