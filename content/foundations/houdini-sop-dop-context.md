## 概要

Houdiniでは、作業の場(**コンテキスト**)が役割ごとに分かれている。**SOP**(Surface Operators)は、ジオメトリを作る・加工する場。**DOP**(Dynamics Operators)は、物理シミュレーションを動かす場。形を作ってからシミュレーションにかけ、結果を再びSOPで仕上げる、という流れがよく使われる。

## 基礎文法

| コンテキスト | 役割                                       |
| ------------ | ------------------------------------------ |
| SOP          | ジオメトリの作成・加工                     |
| DOP          | 物理シミュレーション(重力・衝突・流体など) |
| OBJ          | シーン内のオブジェクトの管理               |

## つまずきやすい点

- DOPは、時間とともに状態が変わる計算を行う。再生位置を巻き戻すと、結果が再計算される場合がある
- シミュレーションは重くなりやすい。キャッシュ(結果の保存)を使って、再計算を避ける
- SOPで作った形が、そのままDOPに入るわけではない。入力として取り込む設定が必要

## 実装例(コード)

```python
import hou

geo = hou.node("/obj").createNode("geo", "my_geo")        # オブジェクトの中にジオメトリを作る
box = geo.createNode("box")                                # SOPのノードを作る
```
