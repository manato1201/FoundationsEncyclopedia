## 概要

コンポジットは、レンダリングした画像を、**ノード**で加工して仕上げる工程。再レンダリングをせずに、色の調整や効果の追加ができる。複数の画像を重ねて合成することもできる。

## 基礎文法

| 要素         | 役割                                   |
| ------------ | -------------------------------------- |
| 入力         | レンダリングした画像や、読み込んだ画像 |
| 加工のノード | 色の調整・ぼかし・合成などを行う       |
| 出力         | 最終的な画像の出力                     |

## つまずきやすい点

- コンポジットのノードを使う設定をしていないと、ノードをつないでも、結果に反映されない
- レンダリングは、画像の元データ(パス)を分けて出力すると、あとから調整しやすい
- 処理を重ねすぎると、確認や書き出しが遅くなる。必要な加工に絞る

## 実装例(コード)

```python
import bpy

scene = bpy.context.scene
scene.use_nodes = True                       # コンポジットのノードを有効にする(バージョンにより設定方法が異なる場合がある)
tree = scene.node_tree
blur = tree.nodes.new("CompositorNodeBlur")  # ぼかしのノードを追加する
```
