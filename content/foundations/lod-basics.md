## 概要

LOD(Level of Detail、詳細度)は、カメラから遠いオブジェクトほど詳細な形状を必要としないという性質を利用し、距離に応じて低ポリゴンのモデルやテクスチャに自動的に切り替える最適化テクニック。近くでは高精細なモデル、遠くでは簡略化されたモデルを使うことで、見た目の破綻を最小限にしつつ描画負荷を下げる。

## 基礎文法

```
距離 0〜10m:  LOD0(高精細、10,000ポリゴン)
距離 10〜50m: LOD1(中精細、2,000ポリゴン)
距離 50m〜:   LOD2(低精細、200ポリゴン)
```

- ランドスケープ([ランドスケープの基礎](/foundations/unreal-landscape-basics))のような広大な地形システムには、LODの仕組みが標準で組み込まれていることが多い

## つまずきやすい点

- LODの切り替わる距離の設定が粗すぎると、切り替わる瞬間にモデルの見た目が急に変化する「ポッピング」という視覚的な違和感が生じる。切り替わり地点にブレンド(徐々にフェードさせる)処理を加えることで軽減できる
- LODごとに個別のモデルを用意する作業自体にコストがかかる。近年は自動的にポリゴンを削減してLODモデルを生成するツールも普及しているが、複雑な形状では手動の調整が必要になることも多い
- カメラが高速で移動するシーン(レースゲーム等)では、LODの切り替わりタイミングが頻繁に発生し、想定より負荷が高くなることがある。カメラの移動速度も考慮したLOD距離の設計が必要になる場合がある

## 実装例(コード)

```csharp
// UnityのLOD Group設定例(概念的なコード)
lodGroup.SetLODs(new LOD[] {
    new LOD(0.5f, highDetailRenderers),  // 画面の50%以上を占める場合
    new LOD(0.1f, mediumDetailRenderers), // 10%〜50%
    new LOD(0.01f, lowDetailRenderers),   // 1%〜10%
});
```
