## 概要

**VDB**は、体積(ボリューム)を、少ないメモリで扱えるデータ形式。メッシュをVDBに変換すると、**形をなめらかにしたり、結合したり**する処理が、安定して行える。流体や煙のシミュレーションの土台にもなる。

## 基礎文法

| 操作 | 役割 |
| --- | --- |
| メッシュからVDB | 形を、体積のデータにする |
| VDBからメッシュ | 体積から、ポリゴンを作る |

## つまずきやすい点

- 変換の細かさ(ボクセルサイズ)が粗いと、形が荒れる。細かいと、重くなる
- 変換を繰り返すと、細部が失われる。必要な回数にとどめる
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import hou

geo = hou.node("/obj").createNode("geo")
vdb = geo.createNode("vdbfrompolygons")  # メッシュをVDBに変換するノード
```
