## 概要

Solarisは、Houdiniの中で、**USD**(Universal Scene Description)というシーンの記述形式を使って、レイアウト・ライティング・レンダリングを行う環境。ノードは**LOP**(Lighting Operators)と呼ばれる。シーンを層のように重ねて組むため、元のデータを壊さず、変更を管理しやすい。

## 基礎文法

| 要素     | 役割                    |
| -------- | ----------------------- |
| USD      | シーンを記述する形式    |
| LOP      | USDのシーンを組むノード |
| ステージ | 組み上がったシーン全体  |

## つまずきやすい点

- USDの概念(層・上書き・参照)が、SOPの考え方と異なる。「元に重ねる」感覚に慣れる必要がある
- 同じ名前のパスを指定したとき、上書きの順序で結果が変わる。ノードの並び順を確認する
- Solarisの機能や名前は、Houdiniのバージョンで変わる場合がある。使っている版のドキュメントで確認する

## 実装例(コード)

```python
import hou

stage = hou.node("/").createNode("lopnet", "my_stage")  # LOPのネットワークを作る(構成はバージョンで異なる場合がある)
```
