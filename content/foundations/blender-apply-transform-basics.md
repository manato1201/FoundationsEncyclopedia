## 概要

オブジェクトを拡大したり回転したりすると、**形ではなく、オブジェクトの値**として保存される。**トランスフォームの適用**(Ctrl+A)は、その値を形に反映して、スケールを1、回転を0に整理する。モディファイアや書き出しでの不具合を防ぐ。

## 基礎文法

| 項目 | 適用後の値 |
| --- | --- |
| 位置 | 原点へ(形はそのまま) |
| 回転 | 0 |
| スケール | 1 |

## つまずきやすい点

- スケールが1でないまま、モディファイアや物理を使うと、効き方が意図とずれる
- リンク複製したオブジェクトなど、適用できない場合がある。複製の関係を確認する
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import bpy

bpy.ops.object.transform_apply(location=False, rotation=True, scale=True)
```
