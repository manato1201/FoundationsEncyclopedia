## 概要

**Gitフック**は、コミットやプッシュなどの操作の前後に、自動でスクリプトを実行する仕組み。コミット前にコードの書式やテストを確認する、コミットメッセージの形式を確かめる、といった使い方ができる。

## 基礎文法

| フック | 実行されるとき |
| --- | --- |
| pre-commit | コミットを作る前 |
| commit-msg | コミットメッセージを確定する前 |
| pre-push | プッシュする前 |

## つまずきやすい点

- `.git/hooks` の中のファイルは、クローンしても共有されない。チームで使うには、リポジトリの中にスクリプトを置き、`core.hooksPath` で指定する、専用のツールを使う、などの方法がある
- フックの処理が重いと、コミットのたびに待たされる。短くとどめる
- フックは回避できる(`--no-verify`)。最終的な確認は、CIでも行う

## 実装例(コード)

```bash
#!/bin/sh
# .git/hooks/pre-commit (実行権限が必要)
npm run lint || exit 1
```
