## 概要

**優先度付きキュー**は、「優先度が一番高い要素を、先に取り出す」入れ物。これを効率よく実現するデータ構造が**ヒープ**(二分ヒープ)。ダイクストラ法のような最短経路の探索や、タスクの優先順位の管理に使われる。

## 基礎文法

最小ヒープでは、すべての親が、子より小さいか等しい。配列で表せる。

| 操作 | 計算量 |
| --- | --- |
| 先頭(最小)を見る | O(1) |
| 追加 | O(log n) |
| 先頭を取り出す | O(log n) |
| 全体を並べ替えた状態にする(ソート済み配列) | O(n log n) |

## つまずきやすい点

- ヒープは、先頭だけが最小と保証される。全体が整列しているわけではないので、2番目に小さい要素の位置は決まっていない
- 特定の要素を探すのは、O(n)かかる。探すことが多いなら、別のデータ構造を使う
- 言語によって、標準のヒープは最小ヒープのみの場合がある(Pythonの `heapq` など)。最大ヒープにしたいときは、符号を反転するなどの工夫をする

## 実装例(コード)

```python
import heapq

heap = []
for value in [5, 1, 4, 2]:
    heapq.heappush(heap, value)   # 追加 O(log n)

print(heapq.heappop(heap))  # 1(最小の要素)
print(heapq.heappop(heap))  # 2
```
