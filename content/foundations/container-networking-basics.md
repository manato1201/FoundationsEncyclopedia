## 概要

コンテナは、ホストとは別の**独立したネットワーク**を持つ。外のネットワークからアクセスしたいときは、**ポートを公開**して、ホストのポートとコンテナのポートをつなぐ。同じネットワークのコンテナ同士は、名前で通信できる。

## 基礎文法

| 設定 | 意味 |
| --- | --- |
| -p 8080:80 | ホストの8080を、コンテナの80へつなぐ |
| ブリッジネットワーク | コンテナ同士・ホストをつなぐ仮想ネットワーク |
| ネットワークの作成 | `docker network create` で、独自のネットワークを作る |

## つまずきやすい点

- コンテナの内側の `localhost` は、そのコンテナ自身を指す。別のコンテナへは、名前で接続する
- ポートを公開すると、外からアクセスできる。必要なものだけを公開し、範囲も絞る
- ホスト側のポートが、すでに使われていると、起動に失敗する

## 実装例(コード)

```bash
docker network create mynet
docker run -d --name db --network mynet postgres:16
docker run -d --name web --network mynet -p 8080:80 nginx   # webからは db という名前でdbへ通信できる
```
