## 概要

**ドローコール**は、CPUがGPUへ出す、描画の命令。オブジェクトやマテリアルが多いほど増え、CPUの負荷になる。**バッチング**は、同じ設定のものを**まとめて描画**して、ドローコールを減らす方法。

## 基礎文法

| 方法 | 概要 |
| --- | --- |
| SRP Batcher | SRP(URP/HDRP)で、設定の切り替えを効率化する |
| GPUインスタンシング | 同じメッシュを、1回の命令でたくさん描く |
| 静的バッチング | 動かないものを、事前にまとめる |

## つまずきやすい点

- マテリアルを分けすぎると、まとめられず、ドローコールが増える
- バッチングの条件は、レンダーパイプラインや設定で違う。Frame Debuggerで、実際にまとまっているかを確認する
- 名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```text
# 確認の流れ
Frame Debuggerを開く → ドローコールの数と内訳を見る → マテリアルや設定を見直す → 再計測
```
