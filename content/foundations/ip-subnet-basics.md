## 概要

IPv4のアドレスは32ビットの数で、「192.168.1.10」のように8ビットずつ区切って書く。アドレスは、どのネットワークかを示す**ネットワーク部**と、その中のどの機器かを示す**ホスト部**に分かれ、その境目を**サブネットマスク**(または /24 のようなプレフィックス長)で表す。

## 基礎文法

| 表記 | サブネットマスク | ホスト部 | 使える機器数の目安 |
| --- | --- | --- | --- |
| /24 | 255.255.255.0 | 8ビット | 254 |
| /16 | 255.255.0.0 | 16ビット | 65,534 |
| /30 | 255.255.255.252 | 2ビット | 2 |

使える機器数は、ホスト部のビット数をnとして「2のn乗 − 2」(ネットワークアドレスとブロードキャストアドレスを除く)で求める目安。

## つまずきやすい点

- 「192.168.1.10/24」の `/24` は、ネットワーク部のビット数。数字が大きいほど、ネットワークは小さくなる
- 192.168.x.x などのプライベートアドレスは、家庭や社内のネットワーク内で使う。そのままではインターネットに出られず、NAT(ネットワークアドレス変換)を通す
- 機器の数に余裕がないサブネットは、あとで拡張しにくい。余裕を見て決める

## 実装例(コード)

```python
import ipaddress

network = ipaddress.ip_network("192.168.1.0/24")
print(network.netmask)            # 255.255.255.0
print(network.num_addresses)      # 256
print(ipaddress.ip_address("192.168.1.10") in network)  # True
```
