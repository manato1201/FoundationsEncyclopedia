## 概要

Mayaでは、オブジェクトの位置・回転・拡縮・表示・ライトの強さなど、あらゆる値を**アトリビュート**(属性)として持つ。画面右側の**チャンネルボックス**は、選択中のオブジェクトのアトリビュートのうち、アニメーションのキーを付けられるものを一覧する窓。数値の確認・入力、キーの設定、ロックなどの日常の操作を、ここから行う。

## 基礎文法

| 窓 | 見せるもの | 開き方 |
| --- | --- | --- |
| チャンネルボックス | キーを付けられる主な属性 | 画面右に常に表示 |
| アトリビュートエディター | すべての属性 | Ctrl+A |

| 右クリックの項目 | 意味 |
| --- | --- |
| Key Selected | 選んだチャンネルにキーを付ける |
| Lock Selected | 値を変更できなくする |
| Hide Selected | チャンネルボックスから隠す |

- チャンネルの名前を選んだまま、ビューポート上で中ボタンをドラッグすると、値を連続して変えられる
- キー設定の次の操作は[グラフエディタ](/foundations/maya-graph-editor-basics)で行う

## つまずきやすい点

- ロックした項目や、ほかのノードから接続されて制御されている項目は、そのままでは値を変えられない(表示の色で区別できる)
- キーが付いたチャンネルは、値を変えても、キーを付け直さない限り、時間を動かすと元の値に戻る
- チャンネルボックスに見当たらない属性は、非表示にされているか、キーを付けられない型。アトリビュートエディターで探す
- 値を変えたつもりが、別のオブジェクトを選んでいる。名前の表示を、確認してから入力する

## 実装例(コード)

```python
import maya.cmds as cmds

cube = cmds.polyCube(name="box")[0]
cmds.setAttr(cube + ".translateX", 5)               # 値を入れる
print(cmds.getAttr(cube + ".translateX"))           # 5.0
cmds.setKeyframe(cube, attribute="translateX")      # キーを付ける
cmds.setAttr(cube + ".scaleY", lock=True)           # ロックする
```
