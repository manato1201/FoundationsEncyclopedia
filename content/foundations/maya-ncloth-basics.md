## 概要

**nCloth**は、Mayaで、布や風船のような柔らかいものを物理的に動かす機能。メッシュを布として設定し、重力や衝突に反応させる。計算はNucleusというソルバーが行う。

## 基礎文法

| 要素 | 役割 |
| --- | --- |
| nCloth | 動く布(物理の対象) |
| パッシブコライダー | 布が当たる、動かない物体 |
| Nucleusソルバー | 物理の計算を行う |

## つまずきやすい点

- メッシュの分割が粗いと、布の動きが角張る。細かすぎると、重くなる
- シミュレーションは、前のフレームの結果に依存する。再生は最初から行う
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import maya.mel as mel

mel.eval("createNCloth 0")  # 選択中のメッシュをnClothにする(MELを呼び出す例)
```
