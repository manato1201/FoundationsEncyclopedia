## 概要

MEL(Maya Embedded Language)は、Mayaに標準で組み込まれた、最も歴史の長いスクリプト言語。Mayaのメニュー操作の多くは、内部的にMELコマンドの実行として実装されており、繰り返し行う操作の自動化やカスタムツールの作成に使われる。近年はPythonでのスクリプティング([Maya Python APIの基礎](/foundations/maya-python-scripting-basics))が主流になりつつあるが、MELの理解は既存のツール資産を読み解く上で今も有用。

## 基礎文法

```mel
// 選択したオブジェクトを一括で複製する例
string $selected[] = `ls -selection`;
for ($obj in $selected) {
    duplicate -name ($obj + "_copy") $obj;
}

// スクリプトエディタでコマンドの実行履歴を確認できる
// (メニュー操作をすると、対応するMELコマンドがログに表示される)
```

## つまずきやすい点

- Mayaの「スクリプトエディタ」でメニュー操作を行うと、対応するMELコマンドが自動的に表示される。この仕組みを使うと、「このメニュー操作は内部的にどのコマンドを呼んでいるか」を逆引きでき、スクリプト化の出発点として非常に有用
- MELの配列や変数の型付けは、Pythonのような近代的な言語と比べて制約が多く、複雑なロジックを書こうとすると可読性が落ちやすい。込み入った処理はPythonへの移行を検討するのが実務的な判断になることが多い
- MELコマンドの実行結果を後方引用符(`` ` ``)で囲むと値として受け取れるという独特の構文がある。この構文に不慣れだと、コマンドの戻り値をどう扱えばよいか分かりにくいことがある

## 実装例(コード)

```mel
// 選択中のオブジェクトの名前を一覧表示する
string $sel[] = `ls -selection`;
for ($name in $sel) {
    print($name + "\n");
}
```
