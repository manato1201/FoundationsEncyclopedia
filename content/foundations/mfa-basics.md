## 概要

**多要素認証**(MFA)は、本人確認に、種類の異なる複数の要素を使う方法。パスワード(知っているもの)に、スマートフォンやセキュリティキー(持っているもの)、指紋や顔(本人の特徴)を組み合わせる。パスワードが漏れても、不正なログインを防ぎやすい。

## 基礎文法

| 要素の種類 | 例 |
| --- | --- |
| 知っているもの | パスワード・PIN |
| 持っているもの | スマートフォン・セキュリティキー |
| 本人の特徴 | 指紋・顔 |

## つまずきやすい点

- 同じ種類の要素を2つ重ねても、多要素にはならない(パスワードと秘密の質問は、どちらも知識)
- SMSで送るコードは、手軽だが、乗っ取りや偽サイトに弱い面がある。より強い方式(認証アプリ、セキュリティキー)も選べる
- 偽サイトで、確認コードまで盗まれる場合がある。偽サイトに強い方式(FIDO2/パスキーなど)がある

## 実装例(コード)

```python
import pyotp  # 認証アプリと同じ方式(TOTP)の例

secret = pyotp.random_base32()
totp = pyotp.TOTP(secret)
print(totp.now())          # 30秒ごとに変わる6桁のコード
print(totp.verify('123456'))
```
