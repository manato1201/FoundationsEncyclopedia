## 概要

デルタタイム(Delta Time)は、直前のフレームから今のフレームまでに経過した実時間(秒)を表す値。[ゲームループの基礎](/foundations/game-loop-basics)の中で、位置や速度のようなパラメータをこの値に応じて変化させることで、フレームレートが変動しても一定の速度でオブジェクトを動かせるようになる。

## 基礎文法

```csharp
// デルタタイムを使わない(誤った)例: フレームレートに移動速度が依存してしまう
transform.position += Vector3.forward * speed; // 60fpsと30fpsで移動速度が2倍違う

// デルタタイムを使う(正しい)例: フレームレートによらず一定の速度になる
transform.position += Vector3.forward * speed * Time.deltaTime;
```

60fpsで実行されている場合、1フレームあたりのデルタタイムは約0.0167秒(1/60秒)になる。

## つまずきやすい点

- デルタタイムを掛け忘れると、高性能なPC(高フレームレート)ではゲームが早送りのように進み、低性能な環境(低フレームレート)では逆にスローモーションのように進んでしまう。フレームレート依存のバグの多くはこの掛け忘れが原因
- 一時的に非常に大きなデルタタイム(デバッガでの一時停止からの復帰、読み込みの一瞬のフリーズ等)が発生すると、その1フレームだけ極端に大きく移動してしまい、当たり判定のすり抜けのような不具合を招くことがある。デルタタイムの値に上限を設ける(クランプする)対策が使われることもある
- 物理演算(Rigidbody等)は、通常のフレーム更新とは別の固定間隔で計算される([Unity物理エンジンの基礎](/foundations/unity-physics-basics)参照)ため、物理関連の処理では通常のデルタタイムではなく「固定デルタタイム」を使う必要がある

## 実装例(コード)

```csharp
void FixedUpdate()
{
    // 物理関連の処理では Time.deltaTime ではなく Time.fixedDeltaTime を使う
    rb.MovePosition(rb.position + velocity * Time.fixedDeltaTime);
}
```
