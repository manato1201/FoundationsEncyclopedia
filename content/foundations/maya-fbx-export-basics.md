## 概要

**FBX**は、3Dモデルやアニメーションを、ほかのソフトやゲームエンジンへ渡すための、代表的な形式。書き出す前にシーンを整え、設定を確認して、取り込み先で見え方を確かめる。

## 基礎文法

| 確認項目 | 内容 |
| --- | --- |
| 単位・スケール | ソフトごとに、既定の単位が違う |
| 上方向の軸 | YかZかで、向きがずれる |
| 含めるもの | モデル・アニメーション・カメラなど |

## つまずきやすい点

- 単位や軸の設定が合っていないと、取り込み先で、大きさや向きが違って見える
- 書き出す前に、履歴の削除や値の整理をしておくと、トラブルが減る
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import maya.cmds as cmds

cmds.file("out.fbx", force=True, options="v=0;", type="FBX export", exportSelected=True)
```
