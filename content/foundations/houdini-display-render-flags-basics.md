## 概要

Houdiniのジオメトリ(SOP)のネットワークでは、ノードが多数つながるが、画面に表示されるのは、**表示フラグ**(青)が付いた1つのノードの結果だけ。**レンダーフラグ**(紫)は、レンダリングに使うノードを決める。ネットワークの途中を確認する、複数の枝のうち1つだけを表示する、といった操作を、フラグで行う。[OBJレベルとSOPレベル](/foundations/houdini-obj-sop-levels-basics)を理解したあとに覚えると、整理しやすい。

## 基礎文法

| フラグ | 色(既定) | 役割 |
| --- | --- | --- |
| 表示(Display) | 青 | ビューポートに表示する |
| レンダー(Render) | 紫 | レンダリングの対象にする |
| バイパス(Bypass) | 黄 | ノードの処理を飛ばす |
| テンプレート(Template) | 薄い印 | 参照用に、薄く表示する(編集には影響しない) |

- 表示フラグとレンダーフラグは、各SOPのネットワークで、通常1つずつ
- ノードを新しく作ると、そのノードに両方のフラグが移る設定になっていることが多い(設定による)
- 色や位置は、版・設定で違う場合がある

## つまずきやすい点

- 「ノードを作ったのに何も表示されない」ときは、表示フラグが、別のノードに付いたままのことが多い
- 確認のためにフラグを途中のノードに移したまま忘れると、最終結果とは違う形をレンダリングしてしまう。レンダーフラグも、同じ点に注意する
- バイパスは、ノードを削除するのではなく、処理を一時的に飛ばすだけ。入力が複数あるノードでは、通過させる入力が決まっている
- 表示フラグは、ネットワークの内側の話。OBJレベルの表示(オブジェクト自体の表示・非表示)とは、別に設定される

## 実装例(コード)

```python
import hou

geo = hou.node("/obj").createNode("geo", "flags_demo")
box = geo.createNode("box")
xform = geo.createNode("xform")
xform.setInput(0, box)

xform.setDisplayFlag(True)    # 画面に出す
xform.setRenderFlag(True)     # レンダリングに使う
box.setDisplayFlag(True)      # 途中のノードを確認する(表示フラグを移す)
xform.bypass(True)            # xform の処理を飛ばす
print(box.isDisplayFlagSet(), xform.isBypassed())
```
