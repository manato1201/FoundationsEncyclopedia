## 概要

**リバースプロキシ**は、Webサーバーなどの前に置かれ、クライアントの代わりに通信を受け取って、裏側のサーバーへ中継する。暗号化の終端、負荷の分散、キャッシュ、裏側のサーバーを隠す、といった役割を持つ。

## 基礎文法

| 役割 | 内容 |
| --- | --- |
| TLSの終端 | 暗号化の処理を、プロキシが引き受ける |
| 負荷分散 | 複数のサーバーへ振り分ける |
| キャッシュ | 同じ応答を保存して、再利用する |

## つまずきやすい点

- リバースプロキシ(サーバー側)と、フォワードプロキシ(クライアント側)は別物。向いている側が違う
- 裏側のサーバーから見ると、接続元がプロキシになる。本当のクライアントのIPは、X-Forwarded-Forなどのヘッダーで受け取る
- プロキシが止まると、全体が止まる。冗長な構成を検討する

## 実装例(コード)

```nginx
server {
  listen 80;
  location / {
    proxy_pass http://127.0.0.1:3000;   # 裏側のサーバーへ中継する
  }
}
```
