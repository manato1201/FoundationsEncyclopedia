## 概要

AIのモデルは、数十億個もの数値(重み)でできている。**量子化**は、その数値を少ないビット数で表し直して、容量とメモリの使用量を減らす方法。手元のPCや小さな機器でモデルを動かしたいときに使われる。

## 基礎文法

1つの重みの大きさは、ビット数で決まる。

| 表し方 | 1つの重み | 100万個の重み |
| --- | --- | --- |
| 32ビット浮動小数点 | 4バイト | 約4MB |
| 16ビット浮動小数点 | 2バイト | 約2MB |
| 8ビット整数 | 1バイト | 約1MB |

(重みの数が同じ場合の単純計算。実際のファイルには、重み以外のデータも含まれる)

## つまずきやすい点

- 容量は減るが、**精度は少し落ちることがある**。落ち幅はモデルと用途で違うため、自分の用途で確かめる
- ビット数をむやみに減らせばよいわけではない。減らしすぎると、答えが大きく崩れる場合がある
- 速度が上がるかどうかは、動かす機器と実装による。容量が減っても、速くなるとは限らない

## 実装例(コード)

```python
# 容量の見積もり(重みだけの単純計算)
def model_size_gb(params: int, bits: int) -> float:
    return params * bits / 8 / 1_000_000_000

print(model_size_gb(7_000_000_000, 16))  # 約14.0
print(model_size_gb(7_000_000_000, 4))   # 約3.5
```
