## 概要

ポインタは、変数の値そのものではなく、その変数が格納されているメモリ上の「アドレス」を保持する変数。[C#のunsafeポインタ](/foundations/csharp-pointers-basics)や[Goのポインタ](/foundations/go-pointers-basics)と異なり、C++のポインタはアドレスに対する加減算(ポインタ演算)まで許可されており、[配列の基礎](/foundations/cpp-arrays-basics)で触れた「配列名はポインタとして扱われる」という性質とも密接に結びついている。

## つまずきやすい点

- 初期化していないポインタ(「野良ポインタ」)を逆参照すると、どこを指しているか分からないメモリ領域にアクセスしてしまい、クラッシュや不正な動作を引き起こす。ポインタは宣言時に`nullptr`で初期化し、使用前に有効性を確認する習慣が重要
- ポインタが指していたメモリが`delete`等で解放された後も、そのポインタ自体は古いアドレスを保持し続ける(ダングリングポインタ)。解放後にそのポインタを使ってしまう「解放済みメモリの使用」は、C++で最も多いバグの原因の1つ
- ポインタ演算(`p + 1`)は「1バイト先」ではなく「指している型1個分先」を意味する。`int*`なら4バイト、`double*`なら8バイト進む、という型依存の挙動を理解していないと、意図しないメモリ位置を指してしまう

## 実装例(コード)

```cpp
int arr[3] = {10, 20, 30};
int* p = arr;       // 配列名は先頭要素へのポインタとして扱われる
std::cout << *p << std::endl;     // 10
std::cout << *(p + 1) << std::endl; // 20 (次の要素、+1は「int1個分」進む)
```
