## 概要

**カーブ**は、少ない制御点で、滑らかな曲線を表すオブジェクト。パイプやケーブル、カメラの移動の軌道、立体的な文字などに使える。

## 基礎文法

| 要素 | 役割 |
| --- | --- |
| 制御点 | 曲線が通る点 |
| ハンドル | 点での曲線の向きと張り |
| ベベルの設定 | カーブに断面を与えて、立体にする |

## つまずきやすい点

- ハンドルの種類(自動・ベクトルなど)で、曲がり方が変わる
- カーブのままでは、一部の機能が使えない。メッシュへ変換が必要な場合がある
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import bpy

bpy.ops.curve.primitive_bezier_curve_add()  # ベジェカーブを追加する
```
