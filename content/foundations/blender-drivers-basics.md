## 概要

**ドライバー**は、あるプロパティの値を、**別の値から計算して自動で決める**仕組み。キーフレームの代わりに、関係(式)で動きを決める。ボーンの回転に応じて形が変わる、といったリグで使う。

## 基礎文法

| 要素 | 役割 |
| --- | --- |
| ドライバー | 値を、計算式で決める仕組み |
| 変数 | 元になる値(別のプロパティなど) |
| 式 | 変数から、結果を計算する |

## つまずきやすい点

- 元の値が変わらなければ、結果も変わらない。変数の指定先が正しいかを確認する
- 式が複雑になると、分かりにくくなる。簡単な式に分ける
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import bpy

obj = bpy.context.active_object
fcurve = obj.driver_add("location", 0)   # X位置にドライバーを追加する
fcurve.driver.expression = "frame / 10"  # フレームに応じて動かす
```
