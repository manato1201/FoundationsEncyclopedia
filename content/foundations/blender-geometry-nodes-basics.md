## 概要

ジオメトリノードは、Blenderで**ノードをつないで形を作る**仕組み。手作業で形を直接編集するかわりに、処理の流れをノードで組み、パラメーターを変えるだけで、形を作り直せる。木や草を大量に配置する、規則的な形を作る、といった用途に向く。

## 基礎文法

| 要素                       | 役割                                            |
| -------------------------- | ----------------------------------------------- |
| Group Input / Group Output | 元の形の入力と、結果の出力                      |
| ノード                     | 点の移動・複製・マテリアルの設定など、処理の1つ |
| ソケットの接続             | 処理の流れと、データの受け渡し                  |

## つまずきやすい点

- 元のメッシュは、ノードによって変形されるだけで、書き換わらない。結果を固定したいときは、モディファイアを適用する
- ノードをつないだのに結果が変わらないときは、出力へつながっているかを確認する
- 要素が多いと重くなる。複製した大量のものは、インスタンスとして扱うと軽く済む

## 実装例(コード)

```python
import bpy

obj = bpy.context.active_object
modifier = obj.modifiers.new(name="GeometryNodes", type="NODES")  # ジオメトリノードのモディファイアを追加
```
