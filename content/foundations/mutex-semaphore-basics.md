## 概要

複数のスレッドが同じ変数を同時に書き換えると、結果が壊れる(競合状態)。これを防ぐのが**ミューテックス**(排他制御)で、同時に1つのスレッドだけを通す。**セマフォ**は、カウンターを持ち、決まった数まで同時に通す。

## 基礎文法

| 仕組み | 同時に入れる数 | 例 |
| --- | --- | --- |
| ミューテックス | 1つ | 1つの変数の更新を守る |
| セマフォ | N個まで | 同時に使える接続数を制限する |

## つまずきやすい点

- ロックを取ったまま例外などで抜けると、解放されず、ほかのスレッドが永久に待つ。解放を確実にする仕組み(finallyやwith)を使う
- 複数のロックを違う順序で取ると、デッドロックになる。取る順序をそろえる
- ロックの範囲が広すぎると、並列の利点が失われる。守る範囲は必要最小限にする

## 実装例(コード)

```python
import threading

count = 0
lock = threading.Lock()

def add():
    global count
    with lock:          # 抜けるときに自動で解放される
        count += 1
```
