## 概要

**キーフレーム**は、ある時間での値を記録した点。2つのキーの間は、Blenderが**自動で補間**して、アニメーションになる。位置・回転・拡大・色・マテリアルの値など、多くの値にキーを入れられる。

## 基礎文法

| 操作 | 役割 |
| --- | --- |
| I | 現在の値をキーとして挿入する |
| タイムライン | フレームを移動・再生する |
| グラフエディター | 補間の曲線を編集する |

## つまずきやすい点

- キーを入れ忘れたプロパティは、動かない。キーを入れた項目が、色で示される
- 自動補間は、緩やかに始まり終わる。一定の速さにしたいときは、補間の種類を変える
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import bpy

obj = bpy.context.active_object
obj.location = (0, 0, 0)
obj.keyframe_insert(data_path="location", frame=1)
obj.location = (0, 0, 5)
obj.keyframe_insert(data_path="location", frame=48)
```
