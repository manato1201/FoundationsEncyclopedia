## 概要

PDG(Procedural Dependency Graph)は、Houdiniで、多数の作業を**ノードでつないで管理・並列実行**する仕組み。作業は **TOP**(Task Operators)というノードで組む。たとえば、条件を変えたシミュレーションを大量に試す、多数のカットをまとめてレンダリングする、といった用途に向く。

## 基礎文法

| 用語           | 意味                                           |
| -------------- | ---------------------------------------------- |
| ワークアイテム | 処理の1単位(1つのファイルや、1つの条件など)    |
| TOPノード      | ワークアイテムを作る・加工する・実行するノード |
| 依存関係       | 前の処理が終わってから次が始まる関係           |

## つまずきやすい点

- 並列に動かすと速くなるが、メモリやディスクの使用量も増える。同時に動かす数を調整する
- 結果の保存先が重なると、上書きされる。ワークアイテムごとに、保存先の名前が変わる設定にする
- 失敗した作業だけを再実行できるが、前の工程の結果が残っていることが前提。キャッシュの扱いを確認する

## 実装例(コード)

```python
import hou

topnet = hou.node("/obj").createNode("topnet", "my_topnet")  # TOPネットワークを作る
```
