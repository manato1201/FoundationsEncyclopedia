## 概要

**UV**は、3Dの表面の各点を、**2Dの画像のどこに対応させるか**を決める座標。UVがあると、テクスチャ画像を、モデルに貼れる。展開のしかたで、模様のゆがみが変わる。

## 基礎文法

| 用語 | 意味 |
| --- | --- |
| UV | 表面と画像の対応を表す座標 |
| シーム | 展開のときに切る境目 |

## つまずきやすい点

- UVが重なっていると、ベイクなどで、情報が混ざる
- ゆがみが大きいと、模様が引き伸ばされて見える。チェッカーで確認する
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import hou

geo = hou.node("/obj").createNode("geo")
uv = geo.createNode("uvtexture")  # 簡易にUVを作るノード
```
