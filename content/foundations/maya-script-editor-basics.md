## 概要

**スクリプトエディタ**は、Mayaで行った操作が、**コマンドとして記録**される画面。上の欄にはその履歴が、下の欄には、自分で書くコマンドを入れる。操作に対応するコマンドを知る手がかりになり、繰り返す作業を、自動化できる。

## 基礎文法

| 部分 | 役割 |
| --- | --- |
| 履歴の欄 | 実行されたコマンドが表示される |
| 入力の欄 | コマンドを書いて実行する(MELまたはPython) |

## つまずきやすい点

- MELとPythonでは、書き方が異なる。入力欄のタブを、使う言語に合わせる
- 履歴にすべての操作が出るわけではない。出ない操作は、ドキュメントで調べる
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import maya.cmds as cmds

print(cmds.ls(selection=True))  # 選択中のオブジェクトの名前を表示する
```
