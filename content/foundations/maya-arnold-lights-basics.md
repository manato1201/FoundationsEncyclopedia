## 概要

Mayaに組み込まれているレンダラー**Arnold**には、専用のライトがある。**エリアライト**は、面で光り、柔らかい影を作る。**スカイドーム**は、空全体から光を当てて、環境光を作る。ライトの強さ・色・大きさで、見た目が大きく変わる。

## 基礎文法

| ライト | 特徴 |
| --- | --- |
| エリアライト | 面で光る。大きいほど影が柔らかい |
| スカイドーム | 空全体からの光。環境光や反射に使う |
| ポイント・スポット | 点や円錐の光 |

## つまずきやすい点

- ライトを増やしすぎると、レンダリングが重く、調整も難しくなる。少ない数から始める
- 強さの数値は、レンダラーの設定と組み合わせて見え方が変わる。見た目で判断する
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import maya.cmds as cmds

cmds.shadingNode("aiAreaLight", asLight=True)   # Arnoldのエリアライトを作る
```
