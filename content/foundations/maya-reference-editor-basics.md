## 概要

**リファレンス**は、別のファイルを、そのシーンの中へ**参照として読み込む**機能。元のファイルを直すと、参照しているすべてのシーンに反映される。共有の素材を、複数のシーンで使い回すときに便利。

## 基礎文法

| 方法 | 特徴 |
| --- | --- |
| インポート | ファイルの内容を、シーンにコピーして取り込む(元との関係は切れる) |
| リファレンス | 元のファイルとの関係を保つ(更新が反映される) |

## つまずきやすい点

- 参照したファイルの場所が移動すると、読み込めなくなる。ファイルの置き場所を、プロジェクトで決めておく
- 参照先のオブジェクトを、シーン側で直接編集する範囲には、制限がある
- 操作の名前や場所は、バージョンによって異なる場合がある。

## 実装例(コード)

```python
import maya.cmds as cmds

cmds.file("rig.ma", reference=True, namespace="rig")  # 参照として読み込む
```
