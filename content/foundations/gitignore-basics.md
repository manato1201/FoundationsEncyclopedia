## 概要

`.gitignore`は、Gitが追跡(トラッキング)しないファイルやディレクトリのパターンを指定する設定ファイル。`node_modules/`のような依存関係、`.env`のような秘密情報、`*.log`のようなビルド生成物など、リポジトリに含めるべきでないファイルを指定するために使う。

## 基礎文法

```
# コメント行
node_modules/       # ディレクトリごと除外
*.log                # 拡張子でパターンマッチ
.env
.env.*.local
!important.log       # !を先頭に付けると除外の除外(このファイルだけは追跡する)
```

## つまずきやすい点

- `.gitignore`に追加しても、既に`git add`でトラッキングされてしまっているファイルには効果がない。一度追跡されたファイルを除外対象にしたい場合は、`.gitignore`への追記に加えて`git rm --cached <ファイル>`で明示的に追跡を解除する必要がある
- APIキーやパスワードのような秘密情報を含むファイルを誤ってコミットしてしまった場合、後から`.gitignore`に追加しても、過去のコミット履歴には既にその情報が残ってしまっている。履歴からの完全な削除には`git filter-repo`のような別の手段と、漏洩したキー自体の失効・再発行が必要になる
- チーム内で共通の除外ルールは`.gitignore`に、個人のエディタ設定など各自の環境依存の除外ルールは`.git/info/exclude`(リポジトリにコミットされない)に分けて管理すると、余計な設定でリポジトリを汚さずに済む

## 実装例(コード)

```
### Node.js
node_modules/
.next
*.log

### 環境変数
.env
.env.local
```
